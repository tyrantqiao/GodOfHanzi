# 汉字成圣

网页端 2D 横版战斗原型。

## 启动

```bash
npm run dev
```

默认地址：

```text
http://localhost:5173
```

## 当前实现

- 对战界面原型。
- 上半部分：AI 绘制水墨雪林背景、下雪特效、火柴人主角、导师剪影、霜藤妖。
- 下半部分：角色状态、HP/精神条、汉字技能卡、右侧技能说明。
- 技能选择：点击 `刀`、`斩`、`静`、`定` 会更新选中态、攻击预览和说明。
- 角色交互：我方回合点击沈砚或陆青崖选择出招角色，保留血条和精神条，不显示行动条。
- 轮流对攻：我方出招一次，敌方反击一次，再进入下一回合；选字、书写和等待不会触发敌人攻击。
- 技能：刀直接攻击，斩按书写评分结算伤害，静恢复生命并净化，定使敌方跳过一次反击。调息占用一次行动并恢复20精神。
- 书写限时30秒：点击“落笔成招”、按住笔尖划出画布边界、倒计时结束均可完成书写并出招；重写不重置时间，空白超时返回选招且不扣蓝。
- 书写评分同时计算覆盖率和准确率：两项均达到90%触发满威力水墨特效；其他情况威力为两项乘积，低于20%触发嘲讽。画布涂满比例达到65%且准确率低于55%判为涂抹，无法施法。失败仍扣蓝并交给敌方反击；定身和净化要求至少50%威力。
- 暂停菜单可存取档；敌方回合中保存会保留待执行反击，读档后继续。
- 存档：支持浏览器 `localStorage`，通过本地服务运行时也支持写入 `data/save.local.json`。

## 数据文件

```text
data/
  battle-state.json      战斗初始状态
  hanzi-skills.json      汉字技能配置
  default-save.json      默认存档
  save.local.json        本地服务写出的玩家存档，首次保存后生成
```

当前存档会保存：

- 当前章节。
- 当前选中角色。
- 当前选中技能。
- 已解锁汉字。
- 完整战斗状态，包括角色和敌人的血量、精神值、品级、境界、状态，以及回合数、当前行动方和反击目标。旧存档的行动条自动移除。

## 技术说明

当前没有引入前端框架和构建工具，先用原生 HTML/CSS/JS + Node 静态服务搭建可运行原型。这样能快速验证界面和交互，后续可以平滑迁移到 Vite、React 或 Phaser。

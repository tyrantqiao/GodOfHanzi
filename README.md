# 当前玩法：刀盾开局与奇遇构筑 v0.3

每局从刀×5、盾×5开始。新字卡来自30个古人对话、诗词答题、原创挽词、冒险、亲笔制卡与小说彩蛋；通关也不跳过成长。支持23张实体卡、17种组合、6件遗物和两名首领。

李白首遇可论王维的诗、赞《将进酒》或借笔亲写一张卡。书写达标得强化卡，真实笔迹留在卡面；稳笔辅助取得普通卡。历史人物均为古代人物，小说彩蛋明确标识。战后只奖励基础刀盾，笔斋回血、强化或删牌。

新存档version:3记录奇遇和完成的笔迹，v1／v2使用各自冻结规则继续。原制卡练习在tutorial.html，旧战斗在legacy.html。召唤与十八层仍为后续范围。

玩法见[爬塔设计](docs/system/tower-design.md)，事件见[奇遇库](docs/content/tower-event-catalog.md)，字卡见[内容目录](docs/content/tower-card-catalog.md)，资产见[资产清单](docs/system/tower-assets.md)。运行npm run dev，验证npm test，整局检查npm run tower:playtest，资产重建npm run tower:assets。

## 旧版书写战斗实现（legacy.html）

- 对战界面原型。
- 雪林教学战以霜藤缠身、陆青崖写「刀」救援开场；玩家点击“执笔迎战”后直接写「火」。战斗中途有霜藤异变提示，胜利时留下圣碑伏笔。
- 首次完美书写有强化的觉醒特效与战斗音效；角色语音仍需可选的本地模型。
- 四字分别有成术表现：「火」点燃、火舌推进并爆燃；「刀」斩出交错刀痕，火刀连招变为焰刃；「止」在敌人身上收拢封印，笔力不足则封印散去；「生」在施法者身边生长回春光环。伤害与治疗数字跟随命中时刻出现，不再靠通用字形飞撞表达效果。
- 描字时，画布墨迹、战场字势、提示词与蓄势条随当前汉字切换色彩；只改变可见反馈，书写评分仍使用原始墨迹像素。
- 上半部分：AI 绘制水墨雪林背景、下雪特效、火柴人主角、导师剪影、霜藤妖。
- 下半部分：角色状态、HP/精神条、汉字技能卡、右侧技能说明。
- 战斗页随浏览器视口铺满，不再要求整页上下滚动；窄屏把角色、字牌和操作压入同一视口，较长说明只在说明区内部滚动。
- 师父提示只在选字、书写与关键反馈时短暂出现，可点师父旁的「师」按钮重看或手动收起；选牌提示不反复朗读。语音保留完整字幕，但改念简短台词，并调节语速与清晰度滤镜。
- 技能选择：点击 `火`、`刀`、`止`、`生` 会更新选中态、效果预览和说明。
- 角色交互：我方回合点击沈砚或陆青崖选择出招角色，保留血条和精神条，不显示行动条。
- 轮流对攻：我方出招一次，敌方反击一次，再进入下一回合；选字、书写和等待不会触发敌人攻击。
- 技能：火造成伤害，威力至少25%时留下灼痕；刀消耗灼痕打出1.6倍焰刃伤害，支持主角起手、师父接刀；止在威力至少50%时阻断一次反击；生回血，威力至少50%时净化寒蚀、恐惧并压下敌方狂暴。沈砚开局受寒蚀且未满血，让「生」有明确救场用途。调息占用一次行动并恢复20精神。
- 书写时战场持续可见，字势随笔迹实时凝聚。限时30秒：点击“落笔成招”、按住笔尖划出画布边界、倒计时结束均可完成书写并出招；重写不重置时间，空白超时返回选招且不扣蓝。
- 书写评分同时计算覆盖率和准确率：新手关卡（当前雪林教学战）覆盖达到50%、准确达到55%即可触发满威力水墨特效，普通关卡仍要求两项均达到90%；反馈显示真实笔迹契合度与最终威力。其他情况威力为两项乘积，低于20%触发嘲讽。画布涂满比例达到65%且准确率低于55%判为涂抹，无法施法。失败仍扣蓝并交给敌方反击；定身和净化要求至少50%威力。
- 暂停菜单可存取档；敌方回合中保存会保留待执行反击，读档后继续。
- 存档：支持浏览器 `localStorage`，通过本地服务运行时也支持写入 `data/save.local.json`。

## 数据文件

```text
data/
  battle-state.json      战斗初始状态
  hanzi-skills.json      汉字技能配置
  default-save.json      默认存档
  save.local.json        本地服务写出的玩家存档，首次保存后生成
```

当前存档会保存：

- 当前章节。
- 当前选中角色。
- 当前选中技能。
- 已解锁汉字。
- 完整战斗状态，包括角色和敌人的血量、精神值、品级、境界、状态、新手演出标记，以及回合数、当前行动方和反击目标。旧存档的行动条自动移除。

## 技术说明

当前没有引入前端框架和构建工具，先用原生 HTML/CSS/JS + Node 静态服务搭建可运行原型。这样能快速验证界面和交互，后续可以平滑迁移到 Vite、React 或 Phaser。
## 新手关：雪林制卡

首页先接受长者亲笔制作的两张三星赠卡，依次使用「火」「刀」脱险；赠卡使用后永久燃尽。随后固定制作自己的「火」「刀」两张卡，两张完成后才进入残碑实战。玩家书写的墨迹直接成为卡面主字，并随卡实例保存；暂收笔案也能保留未完成的笔迹。

长者护持让有效书写轻松达到一星完美，不代写、不替换玩家笔迹；空白、单点与漫墨需要重写。自由笔势探索按已提供的笔势范本匹配，达标获得二星逸品和效果提升，目前不识别任意书法字体。卡片采用一至七星的结构等级，书写品质单独展示；当前实际开放一、二星自制卡和三星长者卡。

自制卡战每回合恢复3文气、最多抽5张，牌组目前仅含两张亲笔卡，敌人展示意图，玩家主动结束回合。支持抽弃燃尽区、v4 存档、未完成制卡恢复和待敌方行动恢复；v3 原型存档需重开，旧版入口保留。数值、配方及星级在 `data/tutorial-cards.json`，纯规则在 `src/card-tutorial-core.js`，详细规则见 `docs/system/card-ranks-and-tutorial.md`。完整分支地图、随机奖励、删卡与遗物仍为后续设计。

新手制卡限时：火45秒、刀35秒（含10秒护持），首笔计时，重写不续时。每张卡可用一次续墨香加15秒。金边与卡画随书写显形；严重失笔会成为废纸，失败不扣纸墨。

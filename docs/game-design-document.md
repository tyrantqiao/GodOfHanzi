# 《汉字成圣》游戏设计文档 v0.2

## 1. 项目定位

### 1.1 一句话概念

玩家扮演一名从地球穿越到寒冬纪元的文道修行者，通过书写汉字、吟诵经典、唤醒汉文化与地球文明中的精神力量，在妖怪横行的大陆上走出一条“以文字成圣”的道路。

### 1.2 核心卖点

- 汉字即技能：每个汉字都可以成为战斗能力、状态能力或规则能力。
- 书写决定强度：玩家用鼠标或触控描摹汉字，系统根据重合度、笔画完整度、结构准确度计算技能效果。
- 文明反哺异界：主角来自地球，可以带来真实历史、诗词、典籍、法律观念和书法传承。
- 低成本高表现：网页端 2D 横版战斗，使用小人角色、文字特效、气泡台词和镜头震动营造爽感。
- 从识字到成圣：游戏让玩家重新接触汉字的形、义、源流与文学力量，而不是只把汉字当作普通技能名。
- 后期分支成道：律法、戒律、宗教性约束与现代文明规则意识，会在中后期成为区别于传统文道的进阶分支。

### 1.3 平台与部署

- 目标平台：网页端。
- 操作设备：优先支持桌面浏览器，后续适配移动端触控。
- 部署方式：前端静态资源可部署到服务器、对象存储或 CDN；若后续需要账号、存档、排行榜、玩家字库，则增加后端服务。

### 1.4 目标体验

玩家应该感到：

- “我写下这个字，它真的在世界里产生了力量。”
- “汉字、诗词和书法不是百科资料，而是可以被我使用、组合和炫耀的能力。”
- “我可以通过理解字义、历史和文学典故，发现更强的战斗解法。”

## 2. 世界观

### 2.1 世界背景

故事发生在一片神奇大陆。这里存在多条登临圣境的道路：

- 妖道：妖怪、灵植、异兽吸纳天地异力，化形、吞噬、蜕变。
- 拳法：以肉身气血破敌，近身爆发，重视筋骨、意志和战斗本能。
- 剑道：以剑意、剑招、剑心为核心，追求一击破万法。
- 刀道：重势、重断、重杀伐，有“刀圣”一类传说人物。
- 文道：以文字、文学、典籍、辩论、浩然气与精神力量修行。
- 律法之道：文道中后期分支之一，源于戒律、宗教性约束、现代法律与文明规则意识，通过立规、判定、契约、禁令改变局部战斗规则。

当前世界处于“寒冬纪元”。寒冬不只是天气变化，也是秩序衰败、资源枯竭、妖祸蔓延和战争频发的时代象征。过往圣人留下的屏障、城邦、碑文和律令仍在保护人族，但这些遗产正在被侵蚀。

### 2.2 国家与秩序

主角醒来的国家没有皇帝。它可能是由文院、律庭、城主、军府或圣人遗训共同维持的松散秩序。妖怪横行，边境常年失守，普通人依附城镇、书院和圣人遗迹生活。

待确认：

- 这个国家是“无皇帝但有议会/书院统治”，还是“皇权崩塌后的乱世联盟”？
- 主角所在势力的名称。
- 圣人遗产是偏东方玄幻、诸子百家，还是混合多文明文本？

### 2.3 主角设定

主角从地球穿越而来，醒来时没有完整身份记忆，只保留地球文明知识、现代语言习惯和对汉字文学的认知。他在异界发现：地球上的文字、诗词、典籍和汉文化精神，可以被这个世界的文道体系承认并转化为真实力量。

主角前中期主修文道，后期可解锁律法分支：

- 文学主线：汉字、诗词、文章、典故、名篇、情绪与精神力量。它可以走出李白式的豪迈、杜甫式的忧国忧民、诸葛亮《出师表》式的以身许国，也可以走出玩家自己的文气风格。
- 律法分支：规则、戒律、宗教性约束、现代法律、契约、判词、秩序与战场裁定。该路线中后期解锁，强调“文明如何约束力量”，而不是开局就替代传统文道。

### 2.4 文人九品

文人共有九个品级。品级越高，精神容量、可承载汉字数量、长句能力、书写速度、抗污染能力越强。律法分支在中后期解锁后，会额外提升规则范围和裁定强度。

暂定品级框架：

| 品级 | 境界称呼 | 核心能力 |
| --- | --- | --- |
| 九品 | 开窍境 | 初开文窍，借助毛笔等媒介书写单字，触发基础能力 |
| 八品 | 聚气境 | 凝聚文气，可稳定使用短词或二字组合 |
| 七品 | 通文境 | 通晓文意，可调用短句、诗句、典籍片段 |
| 六品 | 立意境 | 字句可附带明确意境，影响范围扩大 |
| 五品 | 成章境 | 可构造文章段落，形成持续战场效果 |
| 四品 | 文胆境 | 文胆成形，抗压、抗惧、抗污染能力大幅提升 |
| 三品 | 文心境 | 文心自明，可形成个人文道风格与稳定流派 |
| 二品 | 著道境 | 自成体系，文字力量可长久留存，可开宗立说 |
| 一品 | 半圣境 | 言出近法，字成天地之理，距离圣境一步之遥 |

待确认：

- 文人体系是否与其他道路共用九品，还是文道独有九品。

## 3. 游戏类型与视角

### 3.1 类型

- 2D 横版剧情战斗 RPG。
- 战斗参考：小体量表现上接近火柴人大乱斗，节奏采用半即时行动条。角色会随时间积累行动值，行动条满后进入指令选择、书写或释放技能。
- 叙事结构：章节制主线 + 关卡战斗 + 技能收集 + 字词探索。

### 3.2 战斗画面

基础战斗界面：

- 左侧显示玩家小人和队友。
- 右侧显示妖怪或敌方角色。
- 中央保留技能特效和文字演出空间。
- 底部或侧边显示技能槽、精神值、状态、当前可书写汉字。
- 当玩家发动新字或关键字时，进入书写大屏。

角色表现采用轻量小公仔：

- 待机：轻微呼吸或摆动。
- 受击：后仰、闪白、击退。
- 攻击：前冲、挥笔、挥刀、抬手、震地。
- 施法：气泡说字，毛笔书写，文字浮现。
- 异常状态：束缚、平静、混乱、寒蚀、怯意等以贴纸化图标和角色动作表现。

## 4. 核心循环

### 4.1 单局战斗循环

1. 进入战斗，观察敌人状态、词条和弱点。
2. 双方行动条随时间推进，速度、状态、场地规则会影响行动条增长。
3. 我方角色行动条满后，时间减速或短暂停顿，玩家选择已装备的汉字、诗句或后期律法技能。
4. 若使用普通已熟练技能，直接演出。
5. 若使用新字、强化字或关键字，进入书写交互。
6. 系统根据书写匹配度计算技能倍率。
7. 结算伤害、状态、行动条击退、场地变化或规则变化。
8. 敌人行动条满后释放普通攻击、妖术或蓄力技能。
9. 战斗结束后获得经验、字义理解、素材、故事线索或新字底板。

### 4.2 长期成长循环

1. 推进剧情，进入新区域。
2. 遭遇妖怪、武者、剑客、文人、律者等敌人。
3. 解锁新汉字、新诗句、新典籍；中后期再解锁律法分支。
4. 通过战斗、探索、教学和事件理解字义。
5. 将字或句装入精神槽。
6. 升品后提高容量，解锁更复杂的组合和规则。
7. 面对更强敌人，用文化知识、书写技巧和策略组合解决问题。

## 5. 汉字能力系统

### 5.1 基础概念

每个汉字是一种潜在能力。低品级时，玩家必须借助毛笔、纸、墨、木简、符纸等媒介书写汉字，才能把精神能量稳定转化为能力。

每个汉字拥有：

- 字形：简体、繁体、异体、书法变体。
- 字义：基础含义和引申含义。
- 类型：攻击、防御、治疗、控制、增益、削弱、位移、召唤、规则。
- 消耗：精神值、媒介耐久、冷却或行动点。
- 熟练度：使用次数、书写质量、剧情理解共同提升。
- 底板：系统显示给玩家描摹的目标字形。
- 隐藏底板：不显示轮廓，玩家凭记忆或书法知识书写。

### 5.2 精神槽

文人每个品级能承载的字有限，类似技能槽。

暂定容量：

| 品级 | 单字槽 | 句槽 | 律法槽 |
| --- | --- | --- | --- |
| 九品 | 3 | 0 | 未解锁 |
| 八品 | 5 | 1 | 未解锁 |
| 七品 | 8 | 2 | 未解锁 |
| 六品 | 12 | 3 | 未解锁 |
| 五品 | 16 | 4 | 分支剧情后解锁 1 |
| 四品 | 20 | 5 | 2 |
| 三品 | 26 | 6 | 3 |
| 二品 | 32 | 8 | 4 |
| 一品 | 40 | 10 | 5 |

待确认：

- 是否希望精神槽更紧张，让玩家每关前做构筑选择。
- 是否允许战斗中临时使用未装备的字，但代价更高。

### 5.3 首批示例字

| 汉字 | 类型 | 效果方向 | 示例表现 |
| --- | --- | --- | --- |
| 刀 | 攻击 | 生成刀形斩击，击退敌人 | 字化作刀光横斩 |
| 斩 | 攻击 | 对单体造成高额切割伤害 | 黑墨斩线贯穿目标 |
| 静 | 控制/净化 | 平复敌人怒意，缓解己方精神负面状态 | 水墨波纹扩散 |
| 定 | 控制 | 短暂停止目标移动或打断技能 | 字落地成印 |
| 盾 | 防御 | 生成护盾吸收伤害 | 墨字成盾 |
| 火 | 攻击/持续 | 造成燃烧 | 字燃成火 |
| 水 | 防御/净化 | 降低灼烧、恢复少量精神 | 水墨流转 |
| 风 | 位移/辅助 | 提高闪避或推动敌人 | 字散为风 |
| 破 | 攻击/驱散 | 破除护盾或妖术 | 字裂开敌方屏障 |
| 镇 | 控制/防御 | 压制妖怪、降低行动速度 | 巨字压下 |
| 明 | 增益/侦测 | 看破弱点、提高命中 | 字光照出敌方破绽 |
| 牢 | 控制/封锁 | 限制目标移动范围 | 地面出现文字牢笼 |

500 字技能库可以分阶段设计：

- 第一阶段：30 个主线教学字，覆盖基础战斗。
- 第二阶段：100 个常用字，覆盖流派构筑。
- 第三阶段：300 个探索字，允许组合、隐藏效果和成就。
- 第四阶段：500 个完整字库，支撑长期内容、活动和玩家研究。

## 6. 书写交互系统

### 6.1 新字使用流程

以“龙”为例：

1. 玩家选择“使用新字”。
2. 输入框出现，玩家键入“龙”。
3. 左侧主角气泡显示：“龙！”
4. 画面转入书写大屏。
5. 系统显示“龙”的底板，玩家用鼠标描摹。
6. 书写结束后计算匹配度。
7. 技能根据匹配度释放，低匹配度可能只出现虚影，高匹配度触发完整龙形气劲。

### 6.2 评分维度

书写评分采用“前期宽松、后期硬核”的成长曲线。主线前期优先保证爽感，让玩家觉得写字能成术；后期挑战、隐藏书法、名家底板和高阶 Boss 会逐步提高要求。

暂定评分由四部分组成：

- 覆盖度：玩家笔迹覆盖底板的比例。
- 越界率：玩家写出底板外的多余比例。
- 结构度：关键部件位置是否正确。
- 连贯度：笔画顺序和书写流畅度是否接近目标。

基础公式：

```text
最终匹配度 = 覆盖度 * 0.45 + 结构度 * 0.30 + 连贯度 * 0.15 - 越界惩罚 * 0.10
技能倍率 = 0.35 + 最终匹配度 * 0.65
```

示例：

前期主线：

- 90% 以上：完美，100% 效果，并触发额外镜头或台词。
- 70%-89%：优秀，85%-99% 效果。
- 50%-69%：可用，70%-84% 效果。
- 30%-49%：勉强成字，50%-69% 效果。
- 30% 以下：失败或只产生微弱效果。

后期挑战：

- 95% 以上：完美，可触发隐藏倍率、名家识别或额外词条。
- 85%-94%：优秀，90%-100% 效果。
- 70%-84%：可用，75%-89% 效果。
- 50%-69%：勉强成字，50%-74% 效果。
- 50% 以下：失败、偏字或被强敌识破。

待确认：

- 是否需要识别真实笔顺，还是 MVP 只做形状匹配？

### 6.3 简繁体与书法变体

同一个字可以有多个可识别版本：

- 简体：适合现代玩家快速使用。
- 繁体：更高基础倍率或特殊效果。
- 篆书、隶书、楷书、行书、草书：后期高级玩法。
- 名家书法隐藏底板：玩家不显示轮廓，凭记忆书写。

当玩家高度匹配历史名家字形时，触发鉴赏演出：

- 旁白或角色识别这是某位书法家的风格。
- 展示简短故事、时代与作品背景。
- 根据字帖稀有度、书法境界和匹配度提供倍率。

暂定倍率：

- 普通底板：1.0x。
- 繁体/古体优秀书写：1.2x-1.8x。
- 名家经典单字：2x-10x。
- 剧情级圣人遗墨：10x-100x，仅限关键战斗或特殊条件。

注意：高倍率需要控制使用频率，避免数值失控。可通过精神消耗、冷却、识别难度、每日次数、剧情限制来约束。

## 7. 文学与典籍系统

### 7.1 长句能力

玩家可以输入古诗、宋词、论语、经典文章、判词等真实文本片段，触发更强的文道能力。内容可以来自中外经典，但必须能被汉字书写、汉文化语境或汉译文学精神有效承载；纯音译、只靠外语音韵成立的内容不进入核心技能库。

设计原则：

- 不要求玩家手写每一个字。
- 玩家先键盘输入或从已解锁文本中选择。
- 最后一个关键字可手写，手写则提升气势、倍率或附加效果。
- 若不手写最后一个字，也能释放基础版本，避免操作负担过重。

### 7.2 识别与存储

当玩家输入内容与历史文本匹配达到 90% 以上时：

- 系统确认文本来源。
- 解锁该句或该段。
- 存入玩家句槽或典籍收藏。
- 首次解锁显示简短解释和来源。

示例能力：

| 文本 | 效果方向 | 设计示例 |
| --- | --- | --- |
| 大风起兮云飞扬 | 风势/群体击退 | 召起大风，推开前排敌人 |
| 会当凌绝顶 | 增益/破惧 | 提升己方精神上限和暴击 |
| 三军可夺帅也，匹夫不可夺志也 | 抗控/意志 | 清除恐惧、魅惑、动摇 |
| 天行健，君子以自强不息 | 持续增益 | 回合开始恢复精神，提升行动力 |
| 己所不欲，勿施于人 | 规则/反制 | 反弹一次负面效果，可作为后期律法分支伏笔 |

待确认：

- 文学内容是否只使用公版古典文本，避免版权风险。
- 是否允许玩家输入现代名句、网络梗、原创句子。

## 8. 律法系统

### 8.1 定位

律法是中后期解锁的分支路线，不是前期开局能力。前期主角主要依靠汉字、诗文、典籍、浩然气、个人意志和文学精神成长；律法分支则代表主角把现代文明中的法律、戒律、宗教性约束、契约精神和公共秩序观念带入异界。

它不是单纯伤害技能，而是改变战斗规则。和文人主线相比，律法更冷静、更克制、更接近“以规则约束万物”。它不追求李白式豪迈、杜甫式忧思或《出师表》式忠义本身，而是把这些精神进一步制度化、戒律化、可执行化。

### 8.2 低级律法示例

律法分支初期不在序章出现，可在第一卷后半或第二卷通过关键剧情解锁。示例能力：

| 律法/规则 | 效果 | 限制 |
| --- | --- | --- |
| 不得近身 | 敌人若试图靠近，会被推回 | 对强敌持续时间短 |
| 不许伤民 | 敌方群攻伤害下降 | 仅在人族城镇或守护战中增强 |
| 言出必行 | 己方下一次声明的行动若成功，获得额外效果 | 失败则反噬 |
| 以牙还牙 | 受到伤害后，下次攻击附带反击倍率 | 有冷却 |
| 立界为牢 | 指定区域内敌人速度下降 | 消耗高 |

### 8.3 律法释放方式

律法可以由三部分构成：

- 主体：谁受影响。
- 条件：在什么情况下触发。
- 裁定：触发后发生什么。

示例：

```text
凡妖藤近我三步者，退。
```

该句可被拆解为：

- 主体：妖藤。
- 条件：近我三步。
- 裁定：退。

MVP 阶段不做自由自然语言解析，先使用预设模板，后续再扩展半自由组合。

## 9. 新手章节设计

### 9.1 开场场景

主角醒来时正在战斗。他被藤蔓妖怪捆住，身体无法移动，精神混乱，技能槽为空。

画面表现：

- 背景：雪雾、破败林道、远处残碑。
- 玩家小人被藤蔓缠住。
- 敌方为藤蔓妖怪，枝条挥动。
- 技能栏全部为空，提示玩家无能为力。

### 9.2 救援角色登场

一名本土文道导师赶到，手持毛笔，在空中写下：

```text
刀！
```

“刀”字化为墨色刀光，斩断藤蔓，击退妖怪。玩家第一次看见“字能成力”。导师会在前期作为引路人与战斗教学角色陪伴主角，之后在某场关键战斗中离去，成为主角真正独立踏上文道的剧情转折。

### 9.3 教学流程

第一场教学拆成三个小段：

1. 受困：玩家尝试移动失败，理解状态异常。
2. 观摩：队友写“刀”，演示汉字技能。
3. 尝试：玩家获得“斩”或“静”，亲自书写并释放。

推荐教学字：

- “斩”：直接反馈强，适合教攻击。
- “静”：差异化明显，教状态与精神负面效果。
- “定”：适合教控制，但可放到第二战。

### 9.4 战后叙事信息

救援者向主角解释：

- 这里是寒冬纪元下的人族边境。
- 妖物横行，人族依靠圣人遗留的城墙、碑文、律令抵抗。
- 文人有九品，低品文人需要毛笔等媒介写字成术。
- 主角身上的精神波动很奇怪，像失忆者，又像携带未知文明的“异乡魂”。

待确认：

- 救援者性格：热血、毒舌、温和、老成、搞笑？
- 第一个敌人是否固定为藤蔓妖怪，还是改为更有寒冬纪元感的“霜藤妖”。

## 10. 角色与敌人设计

### 10.1 玩家角色

主角能力关键词：

- 以字成术。
- 以文载道。
- 以律定界，后期分支能力。
- 以地球文明补全异界断裂传承。

可成长属性：

- 精神值。
- 文气。
- 书写稳定度。
- 字槽容量。
- 句槽容量。
- 律令强度。
- 抗寒蚀。
- 字义理解。

### 10.2 初期队友：暂定“执笔人”

功能：

- 教导文道基础。
- 在剧情中解释世界观。
- 在战斗中提供低阶支援。
- 作为主角理解本土文化的桥。
- 在前期关键战斗中离去，推动主角从“被带着学”进入“独自承担”的成长阶段。

待确认名称。

### 10.3 初期敌人

| 敌人 | 特点 | 教学目的 |
| --- | --- | --- |
| 藤蔓妖怪/霜藤妖 | 束缚、缠绕、吸收精神 | 教控制状态与斩断 |
| 寒鸦妖 | 高闪避、骚扰 | 教“定”“风”“明” |
| 雪尸 | 高血低速 | 教持续伤害与破防 |
| 乱兵 | 人类敌人 | 引出律法和道德选择 |

## 11. 关卡与章节结构

### 11.1 第一章：雪林醒魂

目标：让玩家理解世界观、战斗基础和汉字技能。

关卡：

1. 霜藤之困：新手救援，学会“斩/静”。
2. 破碑林道：学习精神槽和字的装备。
3. 寒鸦围袭：学习控制与命中。
4. 边村夜火：学习保护平民与律法萌芽。
5. 残碑初鸣：主角第一次触发来自地球诗文的异常共鸣。

### 11.2 第一章 Boss

暂定 Boss：霜藤母株。

机制：

- 周期性束缚玩家。
- 召唤小藤蔓。
- 受到“斩”“火”“破”克制。
- 被“静”降低狂暴层数。
- 终局触发主角首次使用诗句或律令。

## 12. 美术与表现

### 12.1 风格方向

- 角色：简化小公仔、火柴人式动作骨架，保留服装剪影和武器特征。
- 世界：水墨、纸纹、寒冬蓝灰、墨黑、朱印红作为核心视觉元素。
- 技能：文字本体必须清晰，字形变成力量的过程要突出。
- UI：像书案、卷轴、碑文、印章，但避免过度拟物导致网页端沉重。

### 12.2 动效优先级

MVP 必需：

- 待机。
- 受击。
- 击退。
- 写字。
- 文字飞出。
- 技能命中。
- 状态图标。

后续增强：

- 连招镜头。
- 名家书法识别特写。
- 诗词大招全屏演出。
- 律法展开时的战场规则线。

## 13. 音频方向

## 14. MVP 范围建议

### 14.1 MVP 目标

做出一个可在网页上试玩的 10-15 分钟原型，证明三件事：

- 横版小人战斗能跑通。
- 玩家写字释放技能有爽感。
- 汉字/文学作为核心机制有辨识度。

### 14.2 MVP 内容

- 1 个序章场景。
- 3 场战斗。
- 1 名主角，1 名队友。
- 4 个基础字：“刀”“斩”“静”“定”。
- 1 个诗句技能。
- 1 个律法伏笔事件，不开放可用律法技能。
- 1 个 Boss。
- 基础存档可暂不做，或只用浏览器本地存储保存进度。

### 14.3 MVP 暂缓内容

- 完整 500 字技能库。
- 复杂书法名家识别。
- 自由律法语义解析。
- 多角色养成。
- 联机、PVP、排行榜。
- 移动端完整适配。

## 15. 技术设计初稿

### 15.1 前端技术建议

可选方案：

- Phaser：适合 2D 横版、动画、碰撞、战斗场景。
- React/Vue + Canvas：适合 UI 和书写交互，但游戏战斗要多写底层逻辑。
- PixiJS：适合 2D 表现，游戏系统需自建。

推荐 MVP：Phaser + TypeScript。

理由：

- 横版角色、碰撞、特效、场景切换成本低。
- Web 部署简单。
- 后续可以将书写画布作为独立 DOM/Canvas 层叠加在游戏场景上。

### 15.2 书写识别 MVP

MVP 不做复杂机器学习识别，先做底板匹配：

- 使用字形图片或矢量路径作为目标底板。
- 玩家输入笔迹记录为点序列。
- 将点绘制到离屏 Canvas。
- 与底板 mask 做像素级重合度比较。
- 输出匹配分数。

后续增强：

- 引入笔画顺序。
- 引入 SVG 路径距离计算。
- 引入手写识别模型。
- 引入书法字帖模板库。

## 16. 内容风险与边界

### 16.1 版权

- 古典诗文、古籍、公版书法资料优先。
- 中外文学均可参考，但核心技能必须能以汉字书写和汉文化语境承载；纯音译、只靠外语声音成立的内容不进入核心技能。
- 现代小说、现代诗、现代歌词和当代书法作品需要谨慎处理。
- 网络小说背景只能借鉴类型元素，避免直接使用特定作品的独创设定、专名、人物和剧情。

### 16.2 文化表达

- 解释汉字和典故时要准确，避免过度牵强。
- 可以浪漫化，但不要把错误知识包装成事实。
- 名家书法介绍需要有来源校验。

### 16.3 难度

- 若书写评分太严，玩家会挫败。
- 若评分太松，书写系统会失去意义。
- 建议主线宽松、挑战关严格。

## 17. 待确认问题

1. 主角性别、年龄、性格是否固定，还是让玩家自定义？
2. 导师性格：热血、毒舌、温和、老成、搞笑，或混合型？
3. 导师离去是牺牲、失踪、背负罪责离队，还是被更高层力量带走？
4. 第一个敌人是否固定为藤蔓妖怪，还是改为更有寒冬纪元感的“霜藤妖”？
5. 第一批汉字能力是否只做常用字，还是一开始就加入“龙”“雷”“剑”等高爽感字？
6. 文人体系是否与其他道路共用九品，还是文道独有九品？
7. 是否允许玩家输入现代名句、网络梗、原创句子，还是严格限制为公版经典？
8. 是否需要玩家账号和云存档，还是 MVP 只做本地存档？

# 字义成物：技能演出与组合设计

## 视觉方向

现行表现统一为水墨淡彩：墨青轮廓、宣纸飞白、低饱和草绿、少量朱砂。刀面用 SVG 断续笔触，火用朱砂墨焰，生用淡彩花木，止用宣纸符带。取消大面积霓虹光晕与多重模糊；仅保留必要的轮廓阴影。使用原生 SVG/CSS，不新增图片生成、框架或依赖，保持原有静态托管与减少动态效果支持。后续资产按同一色板替换，不增加每帧重绘或纹理滤镜。

借鉴《杀戮尖塔》的卡牌辨识度与状态组合思路：每个字有能看清轮廓的实体、明确的作用对象和可识别的残留状态。保留雪林、水墨与文道题材。木、纸、铁、火各有材质，不依赖大片发光圆圈区分技能。

演出统一为「凝聚 → 成物 → 作用 → 消散」，普通施法约 1.6–2.1 秒。完美书写强化实体细节和命中反馈；低笔力缩小实体或使其破损。减少动态效果时保留静态轮廓。恢复围绕实际恢复对象，束缚围绕敌方身体，避免无意义的场景装饰。

## 当前四字

刀火最新造型统一见 [雪林墨卷美术方向](art-direction.md)：刀为墨青布柄长刃，火为炭墨包裹的朱砂焰；卡面、蓄势、成术共用相应 SVG 轮廓。下表中的金色护手已由短墨色护手取代，钢面渐变改为断墨与纸白刀锋。

| 字 | 实体与动作 | 色彩、材质 | 战斗含义与当前实现 |
| --- | --- | --- | --- |
| 火 | 笔端点燃，火舌推进，目标处爆燃 | 炭黑边缘、朱红外焰、暖黄焰心 | 现有火焰推进；达到门槛留下灼痕，作为组合起手 |
| 刀 | 施法者上方凝出有柄、有护手的巨刃，蓄势后挥斩 | 青灰钢面、金色护手，克制冷光 | 短暂召唤物演出；已有灼痕时巨刃附火，与普通刀共用轮廓 |
| 生 | 木质「生」图腾升起，五株藤蔓向上长叶并开花，花粉上浮 | 深绿木纹、浅绿叶、乳白粉红花、金色花心 | 本轮恢复与净化；图腾和花木随演出消散 |
| 止 | 五层带有重复「止」字的纸符，从外向内收拢，交错缠身 | 米白符纸、墨青字、青灰暗部 | 达到控制门槛束缚并阻断反击；不足门槛时符带松散下坠 |

火刀组合先保留火焰附刃这一明显变化，避免只改伤害数字。普通刀要能看清钢刃，焰刃要能看清同一把刀上的火，而不是以光球遮盖实体。

## 构筑扩展设计（尚未实现）

召唤物可以逐步成为卡牌构筑的载体，但应先定义生命周期、行动消耗和存档迁移，再增加独立战斗单位。

| 路线 | 组合提案 | 画面表达 | 决策价值 |
| --- | --- | --- | --- |
| 火 → 刀 | 当前已实现：消耗灼痕，伤害 ×1.6 | 巨刃附焰，斩击喷出火星 | 起手与爆发的顺序 |
| 刀 → 止 | 后续：将召唤刀固定为一回合的护身刃 | 「止」符带锁住悬刀 | 立即攻击或转为防御 |
| 生 → 止 | 后续：文字符带与花藤结合，延长束缚或削弱敌方 | 米白符带间长出叶芽 | 治疗路线转为控制 |
| 生 → 火 | 后续：消耗花木形成一次烈焰盛放 | 花瓣焦化，图腾转为赤焰 | 保留恢复载体或消耗它爆发 |
| 刀 → 刀 | 后续：积累悬刃，再统一释放 | 多把小刃环绕施法者 | 储存资源与选择释放时机 |

先以少量明确的状态词条支持组合，例如「灼痕」「悬刃」「花木」「缚字」。卡牌需直接展示起手状态、消耗状态和结果；新增组合必须同步数据、纯战斗逻辑、测试与存档迁移，避免只有演出却没有规则提示。

本次实现仅升级技能表现，不增加持续治疗、独立召唤行动或新组合结算。

召唤刀在开场救援与成功施放后保留为角色身旁的悬浮装备；火刀使用暖色焰光。它不拥有独立生命值或回合，重新载入存档或重播开场时清理展示。开场霜藤采用四层交错藤环、卷曲分枝和冰刺，被巨刃斩断后散落碎片；减少动态效果时保留静态藤形。

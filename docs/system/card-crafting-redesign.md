# 《汉字成圣》制卡与卡牌构筑改造提案 v0.1

状态：新手关已实现两战制卡闭环（首页），旧版保留在 `legacy.html`。完整章节构筑仍为设计提案，示例数值尚未完成平衡。

## 新手关落地范围

首页现采用「长者赠卡脱险 → 亲制火、刀两张卡 → 自制卡实战」流程。赠卡永久燃尽，自己的笔迹成为卡面主字。护持下轻松完成一星完美，自由笔势探索获得二星逸品及数值提升。实现规则与一至七星等级说明见 [亲笔字卡与新手关规则](card-ranks-and-tutorial.md)。

数据在 `data/tutorial-cards.json`；纯规则在 `src/card-tutorial-core.js`，界面在 `src/card-tutorial.js`。v4存档保存笔迹、草稿、燃尽状态、牌堆顺序与待敌方行动。完整章节、分支地图、奖励三选一、删卡与遗物仍为下文设计提案；其中10张初始牌等提案数值不适用于当前两卡教学。

## 1. 核心定位

玩家是一名以汉字为构纹、以纸墨为媒介的文道制卡师。探索雪林与圣碑，取得字谱和材料，亲手制成字卡，再用有限手牌与文气完成战斗。类型调整为水墨剧情驱动的单人卡牌构筑冒险；章节保留，章节内采用分支节点与局内构筑。

一句话体验：「我写出一张卡，决定它怎样发挥；我打出一组卡，让字义彼此呼应。」

《卡徒》提供制卡者与用卡者、卡片结构与套卡的参考方向；《杀戮尖塔》提供动态构筑、路线风险与资源取舍的参考方向。字谱、纸墨、书写落印、文道与诗文组合属于本项目的原创转译。

## 2. 当前单调的来源

目前四种技能常驻，玩家随时可以选择最优技能；一笔成术后立即迎来一次反击，缺少同回合安排多个动作的空间。精神是存量资源，调息大多只是补充资源；火刀组合已有前后顺序，却没有抽牌、费用或保留机会的取舍。反复描字占据了交互时间，但大部分结果只变成威力倍率。

改造需要同时引入手牌限制、每回合费用、敌人意图和战后构筑，单纯把按钮画成卡牌无法解决这些问题。

## 3. 一章冒险循环

选择路线 → 战斗或事件 → 选择字谱/材料奖励 → 进入制卡案 → 制作、改制或删卡 → 应对精英 → 击败章节首领。

战斗奖励提供三选一字谱或材料，可跳过，不强制扩大牌组。字谱首次获得只解锁本次冒险的制作许可，取得不自动加入一张卡。基础路线保证至少两个制卡节点；进制卡节点之前显示当前可制作配方，避免拿到奖励却一直无法使用。

首个版本采用手工编排的分支图，先验证玩法；成熟后再增加随机路线。首轮目标为一章约 20–30 分钟的原型，时长需实测确认。

## 4. 战斗规则

| 项目 | 提案规则 |
| --- | --- |
| 主角 | 沈砚为唯一作战单位；导师作为开场教学与遗物/事件支持 |
| 文气 | 每回合恢复到 3 点，不跨回合保留 |
| 牌组 | 起始 10 张，支持同名卡的多个独立实例 |
| 抽牌 | 每回合抽 5 张，手牌上限 10 张；超出的抽牌不执行 |
| 出牌 | 可以连续出多张，费用足够且目标合法时结算 |
| 敌方行动 | 点击结束回合后，按提前展示的意图依次行动 |
| 手牌去向 | 回合结束丢弃非保留卡；抽牌堆不足时洗入弃牌堆继续抽牌 |
| 格挡 | 吸收伤害；在下一次玩家回合开始时清空，再抽牌 |
| 消耗 | 本场移入消耗区，下一场重新归入牌组；不等于永久损坏 |
| 生命 | 在节点间保留；初始可暂定 60，敌人数值整套重配 |
| 治疗 | 战内主要使用格挡，持续恢复主要放在休息节点 |
| 结束回合 | 玩家主动决定；没有后台自动敌袭，没有书写倒计时推动回合 |

回合顺序：玩家回合开始（清格挡、回满文气、抽牌）→ 玩家出牌 → 玩家结束回合（丢弃非保留卡、结算灼痕等）→ 按意图执行敌方行动 → 确认胜负 → 生成下一回合意图。

取消每打出一张卡就反击的旧规则。移除战斗中的硬编码调息按钮，回气改为明确的卡牌效果；旧精神条由每回合文气替代，避免两套费用系统并存。

## 5. 制卡规则：字谱 × 纸墨 × 笔势

第一版每次制作只要求三个明确选择，不做自由绘制电路或任意组合属性。

1. 选字谱：决定核心效果，例如火引燃、刀斩击、山防御、止压制。
2. 选一个已验证的纸墨配方：决定卡的战术变体。同一字最多两种初始配方。
3. 书写落印：使用现有画布确认字形并生成独立卡片实例。

材料与效果使用配方白名单；不允许任意纸墨交叉组合造成内容与平衡爆炸。制卡前完整展示成品费用、效果、去向、材料消耗，制作后允许预览再确认入册。

| 配方示例 | 成品 | 战术取舍 |
| --- | --- | --- |
| 火谱＋基础纸＋朱砂墨 | 火·引燃 | 1 费，伤害 4，施加 2 灼痕 |
| 火谱＋薄纸＋朱砂墨 | 火·飞焰 | 0 费，伤害 3，施加 1 灼痕；消耗 |
| 刀谱＋基础纸＋松烟墨 | 刀·斩势 | 1 费，伤害 7；可引爆灼痕 |
| 刀谱＋韧纸＋松烟墨 | 刀·藏锋 | 2 费，伤害 12，保留；可引爆灼痕 |
| 山谱＋基础纸＋松烟墨 | 山·固守 | 1 费，获得 6 格挡 |

纸墨改造提供另一种用途，不做统一的伤害加成。制作、改制和删卡共享制卡节点的行动机会，形成取舍：增加新卡可能稀释抽牌，改制可能补齐费用曲线，删卡可能提高关键连招出现频率。

材料第一版只分基础纸、薄纸、韧纸、朱砂墨、松烟墨。每场奖励保证基础材料；特殊材料通过分支节点取得。制作免费基础卡的额度仍受节点行动次数约束，不能无限量产或刷资源。

## 6. 书写如何保留

主要书写移到制卡与改制环节。正常打牌点击卡与目标即可施放，不每张卡都打开画布。战场仍保留凝字、成物、作用与散墨演出，成品卡可展示玩家原笔迹。

书写质量不直接永久放大所有数值。建议基础效果固定，达到合格便完成制作；达到精工门槛后，可以在两个预先平衡的精工分支中选一个。例：火卡选择首次打出多 1 灼痕或首次打出后获得 1 格挡；同一张卡最多一个精工词条，不能重复书写叠加。

制卡失败可重写，材料只在确认成卡时扣除；不使用强制 30 秒计时。保留模板和辅助描写模式，精工通过有限材料改制也能取得，避免鼠标书写能力成为构筑门槛。现有 flooded/weak 等评分反馈可以复用，但不能直接继承旧威力倍率。

战内「临摹」作为后续可选功能：消耗有限的一次性机会为本场生成临时卡。第一版先不加入，以免打断节奏或形成绕过抽牌限制的最优解。

## 7. 首批卡与构筑方向

初始 10 张：刀·斩势 ×4、山·固守 ×4、火·引燃 ×1、理·调序 ×1。止、生进入早期奖励，避免教程一次引入全部规则。

| 卡 | 费用 | 基础效果提案 |
| --- | --- | --- |
| 刀·斩势 | 1 | 造成 7 伤害；有灼痕时，移除灼痕并额外造成其层数 ×2 的伤害 |
| 山·固守 | 1 | 获得 6 格挡 |
| 火·引燃 | 1 | 造成 4 伤害，施加 2 灼痕 |
| 理·调序 | 1 | 抽 2 张牌，再选择弃 1 张 |
| 止·缓势 | 1 | 使目标本回合每次攻击降低 3 点伤害，最低 0 |
| 生·回春 | 1 | 获得 4 格挡，移除 1 层寒蚀；格挡不叠加治疗 |
| 刀·藏锋 | 2 | 造成 12 伤害，保留；有灼痕时按同样规则引爆 |
| 火·飞焰 | 0 | 造成 3 伤害，施加 1 灼痕；消耗 |
| 守·留势 | 1 | 获得 3 格挡，选择 1 张手牌保留到下一回合 |
| 灰·余烬 | 1 | 施加 3 灼痕；消耗 |
| 墨·聚气 | 0 | 获得 1 文气；消耗 |
| 洗·净纸 | 0 | 选择弃 1 张牌，抽 1 张牌；消耗 |

灼痕：玩家结束回合时，对敌人造成当前层数的伤害，再减少 1 层；刀可以提前消耗全部灼痕换取即时伤害。灼痕伤害不经过格挡。寒蚀：每层使本回合第一张格挡卡少获得 1 格挡，回合开始不会自行叠加；来源必须是敌人明确的意图。所有词条有统一悬浮说明。

三个小流派：

- 引燃斩击：火、灰叠灼痕，刀决定立即爆发还是保留持续伤害。
- 藏锋守势：山、守、生维持防线，保留高费刀等待适合的回合。
- 调序速写：理、洗、墨整理手牌，以薄纸消耗卡集中爆发；不能通过无限重洗产生无代价循环。

第一版「止」不能跳过敌人整个回合，避免低费控制循环；「生」不能无限回血，避免用弱敌刷满生命。

## 8. 一回合示例

敌人意图：攻击 12。当前 3 文气，手牌为火、刀、山、理、山。

选择 A：火 → 刀 → 山。造成 4＋7＋4＝15 伤害，获得 6 格挡，承受 6 伤害，灼痕全部引爆。

选择 B：山 → 山 → 火。获得 12 格挡，直接伤害 4；结束回合灼痕再造成 2 伤害并剩 1 层，承受 0 伤害。

选择 C：先打理，用 1 费换取新的抽牌机会，剩 2 费根据新牌决定攻防；可能找到墨补费用，也可能失去完整的三张组合。

同一手牌因生命、敌人意图与后续路线产生不同解法，这才是改造要增加的决策密度。

## 9. 敌人、遗物与路线

敌人先做三种：霜藤妖（攻击/施寒蚀交替）、藤甲卫（格挡后重击）、食墨蛾（往弃牌堆加入不能打出的污墨卡）。首领用蓄势、多段攻击与召唤阶段考验牌组；完整跳回合控制不进入第一版。

笔、砚、印作为遗物，最多先做 6 件。遗物改变操作规则，例如首回合额外抽一张、每战首次制成的临时卡减费等；第一版不添加与尚未实现系统挂钩的遗物。建议可实现的三件：旧砚（首回合多 1 文气）、竹笔（每战首次打出消耗卡抽 1 张）、残印（每回合首次引爆灼痕获得 2 格挡）。

节点包括普通战、精英、制卡案、休息、事件、首领。休息选择恢复生命或改制一张卡；制卡案选择制作、改制、删卡之一。每种操作必须显示对卡组与材料的实际影响。

## 10. 美术与 UI 配合

保留横版水墨战场。敌人上方清晰展示攻击数值、次数与状态意图。底部由四个常驻技能按钮改为 5–10 张手牌，显示费用、大字、实体淡墨图、两行效果与关键词；抽牌堆、弃牌堆、消耗区数量可点击查看。文气用三枚墨点表达，结束回合用独立朱印按钮。

制卡案使用俯视宣纸桌：左侧字谱，中间画布与成品预览，右侧材料/配方。纸墨用材质区别，费用与去向有文字标签。玩家墨迹作为卡面主字保存，技能实体资产承担战场演出；刀火继续使用当前统一墨绘素材。

## 11. 章节与长期成长

一次冒险内保留生命、卡组、材料和遗物；失败后本次构筑结束。字谱图鉴、见过的配方、故事章节与辅助设置保留，长期解锁增加可选内容，不直接增加开局生命或永久伤害。

提供章节重试与手工教程牌序。首轮保持明确剧情目标「制成引燃卡，击退霜藤，取回残碑字谱」，不立即叠加无限爬塔与复杂家园经营。

## 12. 原型实施顺序

第一阶段：只改战斗。实现卡实例、抽弃消耗区、文气、格挡、敌意图、多卡行动和结束回合，先用上述 10 张固定牌组及现有雪林验证乐趣。

第二阶段：加入一张制卡案和火/刀两条配方，接上现有书写画布；增加战后奖励、改制、删卡，让制作结果真正进入牌组并参与抽牌。

第三阶段：12 张卡、3 种普通敌人、1 首领、6 遗物、一个短分支章节，验证不同构筑均能完成；再增加诗句卡和偏旁构纹。自由组合汉字、自动释义与多材料嵌套先放到后续。

## 13. 代码与存档迁移

保持原生 ES modules，不引入框架或依赖。新增 DOM 无关的 `src/deck.js`（抽牌/洗牌/区域迁移）、`src/card-combat.js`（费用/效果/回合/意图）、`src/crafting.js`（配方/消耗/卡实例）；各模块匹配测试并加入 npm test。`src/main.js` 负责 UI 和演出调度。

卡定义与卡实例分离：定义含费用、效果、关键词与配方许可；实例含唯一 id、definitionId、variantId、craftQuality、一个精工分支和笔迹引用。不同制作的同名卡不能用旧 skill id 当唯一键。原 id dao 实际代表火、zhan 代表刀，迁移中显式映射，不根据 id 字面含义猜测。

run 保存路线、当前节点、牌组实例、生命、材料、遗物和随机状态；combat 保存牌堆实例 id 顺序、当前手牌、费用、格挡、敌意图、状态与当前阶段。已生成的奖励与敌意图一起保存，读档不得重新抽取。存档版本升到 3；旧版只能迁移图鉴/设置并提供新冒险入口，不能把旧的待反击存档当成新卡牌战斗恢复。保留 v2 原型读取路径直至切换完成。

技能演出与结算解耦。明确行动锁，避免快速点击重复出牌；减弱动态效果时仍有相同结算。制卡必须在确认时一次性扣材料并生成实例，取消/重写不产生卡或奖励；保存仍兼容服务端与 localStorage 两条路径。

## 14. 验收标准

抽牌洗牌无卡片重复或丢失；出牌扣费与卡片区域迁移只发生一次；结束回合不遗漏状态与敌人动作；取消目标选择不扣费；移除/消耗/保留分别符合规则。读档恢复各牌堆、敌意图与随机状态，不能靠重载改变结果。

制卡入册后能在后续战斗抽到；同名不同配方显示与效果一致；取消和重写不耗材料；辅助书写与手工书写均有可达的精工路线。一次完整章节至少出现两次有意义的制卡取舍，至少两种构筑可以完成首领，逐次打牌的书写弹窗次数为零。

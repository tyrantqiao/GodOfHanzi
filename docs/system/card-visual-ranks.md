# 字卡等级的视觉规范

参考《炉石》以白、蓝、紫、橙宝石识别稀有度的做法，以及《万智牌》特殊边框和闪面工艺的分层设计。借鉴视觉层级，不复用其边框图案。

- [炉石官方稀有度说明](https://hearthstone.blizzard.com/en-gb/news/10245930/cr%C3%A9ez-et-transformez-vos-cartes-20-06-2013)
- [万智牌官方边框与闪面说明](https://magic.wizards.com/en/news/feature/collecting-foundations)

本游戏星级代表结构等级，不另加一套稀有度数值。一星灰银、二星青蓝、三星鎏金、四星紫玉、五星朱铜、六星曜金、七星月白青玉。前三种可在当前教学实际获得或使用，四至七星仅预置视觉变量，未开放制作。

米白纸面与亲笔墨迹保持清晰。等级体现在外框颜色、内框角饰、宝印、费用印章和成卡展示；三星增加双层鎏金框。一星完美仍为灰银，不因品质变成金色。完美与逸品通过缓慢闪面和柔光表达工艺，不额外增加解释文字。

成卡前不展示星级，成卡结果按实际等级呈现边框与品质，牌册保留完整效果说明。动态闪面不接收鼠标事件，减少动态偏好下关闭动画。

# 《汉字成圣》爬塔玩法设计 v0.3

当前主入口是九层汉字卡牌 Roguelike。规则以本文、data/tower.json 与 data/tower-events.json 为准。旧战斗与制卡练习保留在 legacy.html / tutorial.html。构筑、组合的长期候选见 tower-builds-design.md / tower-combos-design.md。

## 成长循环

每一局统一从刀×5、盾×5开始，不赠强力字卡或开局遗物，通关也不解锁跳过成长的预设。山仍是可以在奇遇里取得的山岳牌，盾是新定义的基础防御牌，两者不混用字印。开局十张牌、60生命；每回合3文气、抽5张，上限10张手牌。

选择路线 → 古人对话／答题／冒险／亲笔制卡 → 选字入册 → 战斗与组合 → 笔斋回血／强化／删牌 → 挑战首领。玩家从得到一张新字、亲手写成卡，到补齐配方，逐步形成构筑。

第1层固定李白「月下论诗」，作为不强迫书写的第一次奇遇。第2层普通战，第3层奇遇；第4层宝阁或奇遇；第5层普通战或精英；第6层奇遇或笔斋；第7层普通战或奇遇；第8层笔斋或奇遇；第9层首领。每层只能完成一个节点，事件收获页点击继续才返回路线。

普通与精英战后回复6生命，奖励仅普通刀／盾，可跳过保持牌册精简；首次精英胜利额外选遗物。宝阁选遗物。强力字卡通过奇遇三选一、答题闯关和亲笔制卡获得，不再从战后普通池或笔斋直接临摹补卡。

## 奇遇规则

当前30个事件：6个古人对话、6组两题闯关、6个原创挽词、6处冒险、3个制卡事件、3个小说彩蛋。名单与选项见[奇遇库](../content/tower-event-catalog.md)。除首遇李白固定外，事件按种子抽取，本局不重复；库大小大于本局可遇数量。

- 论诗：李白可听你讲王维的诗，也可听你赞《将进酒》，或借笔让你制卡。杜甫、苏轼、李清照、陶渊明、王维各有不同的奖励主题。全部人物对白是架空创作。
- 闯关：每次两题，提交后显示解释，明确点击下一题。全对选强化卡、答对一题选普通卡、全错回复4生命，不阻断路线。题型包括诗词与当前卡牌规则。
- 挽词：岳飞、项羽、屈原、文天祥、嵇康、荆轲；文句全部为游戏原创，不标为古人原作。选项没有道德评分或正确答案，均有馈赠；第三项允许亲笔寄意。
- 冒险：炉火、断崖、密室、剑匣、墨溪、藏书楼。入口明确列出生命代价，深入探寻获得强化卡；生命不足不能选择，安全探索仍得普通卡，放弃探索可回血。当前为选择与资源权衡型冒险，尚无冒险专属战斗或概率惩罚。
- 制卡：游方师、王羲之、欧阳询提供纸与字谱；李白和挽词等事件也能提供机会。
- 彩蛋：孙悟空、令狐冲、萧炎以古典／武侠／网文小说彩蛋身份客串，界面明确区分虚构角色与历史人物。无近现代历史人物。

## 亲笔制卡

先选择字谱，再在当前局的画布上临摹，可返回重选、重写。未完成时不消耗机会。画布支持鼠标、触控笔与触摸；不设书写倒计时。无法书写时使用稳笔辅助，取得普通卡。

字谱采用归一化折线，覆盖与准确由DOM无关的几何判定计算：覆盖≥65%、准确≥60%取得强化卡；有效但未达标取得普通卡。空白、单点、越界、非有限或超限笔迹拒绝提交，大片漫墨不能升级。最多32笔、1600个点。它是本轮爬塔的简化临摹规则，并不替换旧教学的像素评分。

亲笔卡面保留实际墨迹。存档记录原始点列，重放时重新计算品质，不信任客户端声称的升级结果。完成获得一张卡后进入结果页，同一机会不能重复领取。关闭画布返回选字；尚未提交的画布草稿不写入爬塔存档，完成后的笔迹会保存。

## 战斗与组合

23张实体卡、17种术式、6件遗物、两名首领。攻击／防守／术法已开放，召唤尚未开放。普通卡独立生效，字印为额外构筑层。灼痕在回合末反击前结算并减1；刀消耗全部灼痕追加每层2伤害。蓄势最多9，跨回合保留，本战结束清空。震把格挡转成伤害并消耗一半格挡；守只保留反击后剩余的有限格挡。

每回合每张实体卡只留一次字印，最多3印，新印替换最早的印。凝式消耗字印，不重复复制卡牌基础效果。一个术式槽，每回合最多2次凝式／进阶、1次释放。术式可保留到下一回合结束，进阶继承原期限。图鉴公开配方，发现记录跨局保留而不加永久数值。气＋旋→气旋丸，继续加入风→风轮刃，再加入火→焰风轮。

遗物只能来自宝阁与首次精英奖励，同名不重复；各自保留每回合／每战限制。笔斋回复18生命／强化一张／删除一张三选一，删后至少8张。敌人保留蓄力与护甲轮替；护甲抵消直接伤害，灼痕绕过护甲。

## 存档与实现

新局 mode: tower、version: 3、contentVersion: tower-3.0，种子与合法操作重放恢复事件题目、已答反馈、待选奖励、亲笔卡与战斗资源。v1继续使用 tower-core-v1.js / tower-v1.json；v2继续使用 tower-core-v2.js / tower-v2.json。旧局不偷偷换卡组或路线，新一局才切换刀盾奇遇规则。仍使用 hanzi-tower-save 与共用单槽 /api/save；模式不符回退本地。

src/tower-core.js 负责路线、战斗与重放；tower-events.js 负责事件结算；tower-craft.js 提供折线字谱与纯评分；tower-combos.js 负责凝式。UI在 tower.js / tower.css，不引入框架、依赖或构建步骤。

npm test 验证规则与旧版兼容；npm run tower:playtest 运行48局、四种奖励偏好，所有策略都从同一刀盾牌组出发，检查合法操作、牌堆守恒与完整重放。模拟策略不是人类胜率或平衡结论。npm run tower:assets 重建55份矢量资产（含6类奇遇画意与新盾牌）。

## 安卓横屏单屏交互

主入口采用固定视口棋盘：顶部生命／层数与牌册、凝式、菜单入口，中央战场显示敌人生命与下一步意图，底部单行手牌，右下角回合资源与结束回合。主页面不纵向滚动；超过一屏的手牌横向滑动。

点击手牌弹出完整卡面、费用与效果，确认后才执行出牌；调序等选牌能力继续使用专用选牌弹窗。凝式与释放位于独立弹窗，战斗结束时自动关闭。牌册、图鉴、奇遇手册、遗物与存档菜单均为弹窗，不占用棋盘高度。

路线、奇遇、奖励、笔斋在中央行动面板切换，长故事与大量待选牌只在面板内部滚动。制卡弹窗横向排列画布和操作按钮，保留触摸笔迹、重写、返回与稳笔辅助。弹窗支持返回按钮和 Escape。手机竖屏显示横置提示；安卓 Activity 使用 sensorLandscape，支持两个横屏方向。适配安全区和动态视口高度，不改变规则与存档版本。

验证：node --check src/tower.js、npm test。仍需在安卓真机检查 800×360、960×540 横屏、十张手牌滑动、长篇奇遇、制卡触控及系统返回键。

本轮行动面板更新为左右分栏：左侧奇遇画意、可展开故事与结算反馈；右侧选项、题目和奖励。正文独立滚动，三选一行动不依赖纵向翻找；小高度奖励卡压缩画意，为跳过预留位置。大量强化／删牌候选沿横向浏览。配色统一为墨青、暖白宣纸与朱砂。安卓原生层沉浸式隐藏系统栏，只保留挖孔／必要手势安全区，网页使用容器实际高度。

启动先进入独立主菜单（开始试炼／继续存档／制卡练习），战场顶栏压缩到36px并改用牌册、凝式与菜单图标。返回主菜单保留当前会话的试炼，通过返回当前试炼继续；退出应用前仍需主动保存。

界面采用背景优先的半透明墨青行动条，图标、行动与简短结果同屏展示；必要生命代价与奖励信息不依赖悬浮。顶部生命／层数／牌组，以及敌人意图、双方资源用图标数值展示。详细规则通过tower-ui.js的悬浮和键盘焦点提示提供；触屏沿用直接选择、卡牌详情与工具面板，不改变结算和存档。

## 设置与更新

主菜单右上角和试炼顶栏统一提供齿轮设置入口。设置可检测更新；试炼中还可进入行囊保存与查阅图鉴，或返回主菜单，当前试炼保留在本次会话。网页版本明确提示更新检测仅适用于安卓安装版。

安卓启动自动检测与设置中的手动检测共用流程，重复请求不会同时下载。更新信息改从 GitHub 最新正式发布的 android-update.json 直链读取，避免 GitHub API 匿名额度耗尽导致的 403；下载跳转逐次验证 HTTPS 与域名。设置显示检测中、最新版本、下载中及失败原因，保留 SHA-256、包名、版本与签名校验，以及安装前保存提示。需要在安卓安装包上验证网络错误后重试、下载及系统安装确认。

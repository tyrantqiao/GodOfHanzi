# 敌人与妖物设计 v0.1

状态：本轮游戏设计提案，尚未修改运行卡池、敌人数据或战斗引擎。当前玩法仍以[爬塔玩法](tower-design.md)为准。本方案覆盖五个敌人家族、15个普通／精英模板、5名首领，并给出分阶段接入顺序。

## 体验目标与共同规则

怪物决定玩家这一回合怎样出牌，也影响下一次奇遇想取什么字。尸类强调破硬壳与抓复苏窗口；赶尸人强调打断控场；邪派强调识破招式与反击；妖怪强调看清真假与限制恢复；邪兽强调读懂蓄力与多段攻击。

每个普通敌人一个主特性，精英最多两个。敌人的下一步攻击、护甲、恢复、反击、召唤都公开显示，悬停解释触发条件、持续时间与上限。首次出现先给一句短提示，不靠玩家受伤之后才发现隐藏规则。弱点是奖励正确时机与操作，不要求带某张卡才能获胜；刀盾牌组也能逐步打赢。

- 第2层只从白衣行尸、山道盗徒、墨牙犬中选，低压、无复活、无控制、无召唤。第1层取到哪种奇遇卡，都不影响能否进入第二层。
- 第5层引入一个新机制；精英才可把两个已见机制组合。第7层开放更完整家族，路线提供家族图标及关键特性摘要。
- 削弱只减少直接攻击；灼痕先于反击结算。破甲与打断都另有明确提示，不能把「止」自动改成当前尚不存在的跳过整回合控制。
- 敌人恢复不得突破最大生命，不复活已结算死亡的单位；复苏仅限未死敌人的预告恢复招式。未来首领换阶段不是重新复活领取奖励。
- 不偷永久卡、不毁玩家亲笔卡、不封锁制卡入口。负面状态本战结束清空，不形成永久惩罚。
- 击杀先于敌方所有待结算动作；灼痕击杀同样立即结束。召唤物不单独发奖励，整场只结算一次。

下列生命／招式数字为指定遭遇层级的目标值，不能再叠加当前通用层数倍率。落地时需换算成基础参数或使用层级模板，模拟验证后再定数值。

## 五个家族与15个模板

### 一、僵尸：硬壳、缓慢、复苏

画面关键词：灰白肤色、旧服、僵直重心、冷色尸气。设计为非写实水墨怪物，避免依赖血腥表现。主特性图标是裂开的骨甲，蓄力时双臂明显前伸。

| 敌人 | 定位／目标生命 | 招式循环与特性 | 应对与构筑启发 |
| --- | --- | --- | --- |
| 白衣行尸 | 第2层普通，32 | 扑抓6 → 蓄力0 → 僵直重击10。无额外被动。 | 重击前存好防守牌；蓄力回合多打刀。任何新字卡都只是帮助，不是门槛。 |
| 铁皮僵尸 | 第5层普通，44 | 骨甲护体：本轮8护甲、攻击7 → 裂甲喘息：0护甲、攻击10。护甲是可消耗临时值，不额外减伤。 | 在喘息轮用重攻击／蓄势爆发；灼痕绕甲，多次攻击逐步消耗同一份护甲。 |
| 尸灯守卫 | 第7层精英，58 | 扑击9 → 点尸灯：0攻击、恢复6生命 → 重击15。点灯招式有6点打断阈值，每次点灯开始重置。 | 点灯轮造成至少6点实际直接伤害即可阻止恢复；基础刀就能做到。已有灼痕也能压过回复，但不计打断值。 |

打断值只计算护甲之后实际扣除的直接伤害，同轮多次攻击累加；过量伤害照常结算，不因为打断而吞伤害。阈值条只在相关招式轮出现。

### 二、赶尸人：符令、尸傀、主人与工具

画面关键词：斗笠、铃、符纸、竹杖；摇铃与贴符各有清晰动作。设定为本游戏原创的邪术操纵者，不泛指真实民俗从业者。

| 敌人 | 定位／目标生命 | 招式循环与特性 | 应对与构筑启发 |
| --- | --- | --- | --- |
| 摇铃尸客 | 第5层普通，40 | 贴符备令：0攻击、获得6护甲 → 驱尸扑击12 → 杖击8。 | 在备令轮削护甲，在扑击轮防守；护甲照当前规则在下一轮刷新／清空，不暗中永久叠高。 |
| 驭尸道人 | 第7层普通，48 | 聚尸气：0攻击、打断阈值7 → 驱尸重击：未打断则16，打断则8 → 杖击9。 | 可以打断降低下一轮压力，也可保留能量以守势接重击。蓄势、灼痕与防守都有可用打法。 |
| 双傀赶尸使 | 后续多目标精英，主体46、尸傀各14 | 主体铃击4，两傀各扑击5；合计14并分项公开。召唤轮仅补回一只尸傀，本战至多补两次。 | 先清一傀降低压力，或优先打断主体召唤。主体死亡立即瓦解剩余尸傀，结束战斗。不把傀儡清空作为第二个胜利条件。 |

首轮接入只做前两种单目标赶尸人。双傀需要敌人列表、目标选择与多段敌方结算，当前引擎还不支持；不能把一份护甲伪装成已经实现的可攻击召唤单位。

### 三、邪恶门派人：招式、反制、资源贪欲

门派均为原创虚构势力：玄灯门偏符阵，血砚门偏吸取，断墨楼偏刀术。敌人与历史人物奇遇不混用，也不把真实宗教或门派设为邪派。

| 敌人 | 定位／目标生命 | 招式循环与特性 | 应对与构筑启发 |
| --- | --- | --- | --- |
| 山道盗徒 | 第2层普通，30 | 斩击7 → 持盾：攻击4、4护甲 → 斩击9。无控制。 | 认识护甲与攻击意图；可以蓄力等待，也可直接以刀消耗护甲。 |
| 血砚门徒 | 第5层普通，42 | 墨刃8 → 血契斩10：若实际伤到玩家则恢复4生命 → 调息0。 | 完全格挡血契斩即可阻止恢复，部分格挡也有价值。不会隔着盾无条件吸血，火刀可在调息轮爆发。 |
| 断墨刀客 | 第7层精英，54 | 迎刀架：攻击5，进入本轮反击姿态 → 三连斩4×3 → 蓄力0。迎刀架本轮前两次直接伤害各反击2，至多4。 | 反击为可被现有格挡吸收的伤害，普通牌先产生格挡再结算其反击；灼痕不触发。可先防守，再用少次重击，或保留术式到下一轮。 |

反击不能触发玩家额外反击形成循环，也不消耗玩家回合末的敌方正常行动。因攻击击杀刀客时不再反击；界面同时显示正常意图与本轮已用反击次数。

### 四、妖怪：伪装、恢复、领域

画面关键词：人形与异形局部并存，狐狸尾影、纸面墨孔、根须；用轮廓差异辨识，外形不替代规则提示。

| 敌人 | 定位／目标生命 | 招式循环与特性 | 应对与构筑启发 |
| --- | --- | --- | --- |
| 狐灯妖 | 第5层普通，38 | 灯影庇护：6护甲、攻击5 → 现形：0护甲、攻击11 → 偷袭7。 | 意图始终真实显示，幻术只体现在护甲与视觉。先剥灯影、现形爆发；不在后台随机交换真假敌人。 |
| 纸魇 | 第7层普通，42 | 折纸8 → 扎纸：0攻击、下一轮8护甲 → 撕纸12。扎纸轮受到任意两次实际直接伤害即取消下轮护甲。 | 多次攻击、抽牌找两张刀都有效；少次重击流仍可等护甲轮过去，或用灼痕绕开。连击每一段分别计数，但零伤害不算。 |
| 枯荣树妖 | 第7层精英，60 | 藤鞭10 → 汲露：0攻击、恢复8 → 根缚14。汲露轮承受至少8点实际直接伤害即可取消回复。 | 爆发与蓄势抓回复窗口；持续灼痕也能削弱恢复优势。第一版不做「没有火就无法伤害」的硬免疫。 |

现有霜藤旧入口资产可作为树妖画面参考，不能直接改旧教学的战斗规则。根缚第一版只是有预告的攻击名称，不额外封锁抽牌或书写。

### 五、邪兽：捕食节奏、多段攻击、冲锋

画面关键词：低伏兽形、墨色裂纹、明显角／爪／骨甲。冲锋前脚步与躯体变化，玩家看动作与意图都能理解危险。

| 敌人 | 定位／目标生命 | 招式循环与特性 | 应对与构筑启发 |
| --- | --- | --- | --- |
| 墨牙犬 | 第2层普通，28 | 嗅探0 → 撕咬8 → 撕咬6。第一轮提供安全观察窗口。 | 用刀抢先削血，之后考虑攻防分配；不加重伤、失血或永久扣生命。 |
| 裂角獠兽 | 第5层普通，46 | 低伏蓄力0 → 冲撞16 → 疲惫踢击5。冲锋没有无视格挡效果。 | 蓄力轮组织术式、下一轮接冲撞；削弱、磐／守势有价值，基础两盾也能大幅减伤。 |
| 骨甲蛛 | 第7层精英，56 | 结甲：8护甲、攻击6 → 撕扯4×3 → 疲软：0护甲、攻击8。 | 格挡是本轮共享池，依次抵消三段；守势适合接多段，但普通盾同样有效。低甲轮打爆发。 |

多段攻击按每段扣剩余格挡，不能每段都重新获得整份格挡。削弱对整次行动的总伤害预算生效：按段依次分配减伤，避免3连击把「止」的减伤收益无意放大三倍。

## 五名首领

普通怪教一个机制，首领只组合玩家已经见过的两到三个机制。全程公开下一招，不突然刷新一整条生命、不重洗玩家牌组。50%生命阶段变化只触发一次，立即显示变化；不立刻追加免费攻击，下一行动才使用新循环。

| 首领 | 目标生命／定位 | 特性与阶段 | 不同构筑的打法 |
| --- | --- | --- | --- |
| 黑棺尸王 | 90，僵尸 | 骨甲12＋爪击8 → 蓄力0 → 开棺重击18。半血后骨甲降为6，重击升为20；舍弃恢复机制，避免拖成无限战。 | 灼痕绕甲、蓄势抓开棺、防守挡重击；半血后的破甲窗口更宽。 |
| 百铃尸师 | 86，赶尸人 | 备令0、打断阈值10 → 驱尸冲击18（打断后10） → 铃杖10。单目标首轮版；多目标版以后再增加一只可清理尸傀并重新调低主体伤害。 | 连击与重击可打断；蓄势等待窗口；守势流硬接冲击。 |
| 血砚门主 | 88，邪派 | 血契斩12，伤到玩家才回复6 → 调息0 → 墨刃16。半血后血契回复改4，墨刃改18。 | 完全格挡阻止回复；调息轮用火刀或组合爆发；不会把吸血收益放大到不可逆。 |
| 镜月狐君 | 84，妖怪 | 幻灯10护甲＋攻击7 → 现形14 → 重新结灯0。半血后幻灯6护甲、现形17。 | 蓄势在现形轮发力，多次攻击剥灯，灼痕绕甲。无随机真假目标，无错误选择必死。 |
| 吞墨獠主 | 96，邪兽 | 低伏0 → 冲撞20 → 撕咬5×2。半血后冲撞22，撕咬降为4×2，继续给出安全组织轮。 | 用准备轮构筑术式；多盾、削弱与保留格挡接冲锋；输出流抢在高压轮前击杀。 |

这些生命和伤害是试玩起点，尚未平衡。当前镇塔墨魇、裂碑巨像仍保留，后续可归为妖怪／邪兽家族或作为独立塔灵，不立即删旧档敌人。

## 与奇遇和奖励联动

战斗本身仍只补基础刀盾、回复生命，精英额外给遗物；强力字卡继续来自奇遇，不把新怪物变成另一个无条件三选一来源。

可增加四种短支线：

1. **废炉尸影**：先参加炉火探险，再挑战铁皮僵尸；胜利解开炉中残页，在同一个奇遇结算里从火／炎／烬选一张。必须显式保存「奇遇战斗来源」，避免战后普通奖励和事件奖励重复结算。
2. **夜铃护送**：与原创旅人对话，选择驱散尸客或避开；战斗胜利得制卡机会，绕行得小额恢复。人物不借用近现代历史身份。
3. **借诗照妖**：完成李白／王维的论诗支线后，遇到狐灯妖；前置诗意仅提供首次结灯护甲-2的可见优势，未遇见诗人也可正常获胜。
4. **剑客辨招**：小说剑客讲解迎刀架，选项给出一个例题；回答正确在该次挑战开场获得3格挡。彩蛋角色作为指路者，不取代本游戏原创首领。

先制作事件与战斗的完整结算桥，再加入这类支线。当前30个奇遇没有专属战斗，这些内容不能在界面宣称已经开放。

## 画面与敌人图鉴

每个敌人至少有完整立绘、待机、攻击预备、受击、击败五种表现；精英增加清晰符印或轮廓变化，首领增加阶段变化。可以用同一立绘配局部动画开始，但名字与轮廓都应能区分，不能只换颜色。

图鉴字段：名称／家族／普通或精英／简短来历／主特性／下一招及完整循环／触发与次数限制／通用应对／相关事件。来历是原创设定，不作民俗史实介绍。首次只讲一句实用提示，例如「它正在摇铃，本轮打够7点伤害可减弱下一轮尸扑」。所有状态在意图区有文字，不能只靠色彩、图标或动画传达。

## 接入顺序与验收

**第一批：现有引擎可承担。** 白衣行尸、山道盗徒、墨牙犬、铁皮僵尸、摇铃尸客、狐灯妖、裂角獠兽；只用单目标攻击／蓄力／可消耗护甲。调整第2／5／7层池与遭遇元信息，保持v3旧存档可重放。

**第二批：新增少量纯规则。** 尸灯、驭尸、纸魇、树妖、血砚门徒；引入打断条、预告恢复、条件吸血与一次性阶段转换。敌人行为由有标识的行动定义驱动，不把数组第几项写死在UI。

**第三批：多段与多单位。** 刀客反击、骨甲蛛多段、双傀尸使；分段伤害和共享格挡先完成，再实现目标选择、主体死亡、召唤上限和召唤物奖励归属。首领按对应机制成熟度分批开放。

每批要验证：刀盾牌组有可行路线；伤害／护甲／打断的顺序；灼痕击杀取消行动；复苏与吸血不超最大生命；击杀不触发反击；多段共享格挡及削弱预算；阶段只转换一次且不追加攻击；旧档沿用原规则；新档在蓄力、打断、阶段转换与召唤待结算处可完整重放。

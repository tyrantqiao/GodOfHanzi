# 亲笔字卡与新手关规则

## 教学顺序

1. 长者交付亲笔三星「火」「刀」，玩家直接接卡，不先书写。
   点击接卡前仅展示赠卡邀请，不展示手牌、费用、敌人状态或出牌引导；接卡后才揭示卡面并提示先用火。
2. 先火后刀破除霜藤。此段长者护住玩家，敌人不反击，赠卡使用后永久燃尽，后续不会洗回牌堆。
   开场沈砚俯身受困，藤蔓覆盖身体并显示「藤蔓缠身」。首次使用赠卡即可解除束缚，火卡呈现烧断藤蔓与起身反馈；刀卡击败霜藤后，妖物后退消散并永久离开当前战场。束缚从已用赠卡推导，兼容原v4存档，不额外改变费用与伤害。
3. 长者提供纸墨与护持，玩家依次亲制「火」「刀」。只设计这两次制卡；失败不耗材料，完成一张才消耗对应纸墨。
4. 两张都完成后进入残碑战。玩家每回合有3文气，自己的卡使用后进入弃牌区，可重新抽取；敌人意图提前公开。

卡面主字使用制卡画布中的真实墨迹，不用字体替换。长者卡使用独立手绘笔迹资源。玩家成卡墨迹以透明256像素PNG保存到独立卡实例；暂收笔案保留400像素草稿，重新打开恢复书写。

界面固定在当前视口内：战场与操作区按窗口高度分配空间，手牌笔迹区域可收缩；制卡案采用画布与说明并排布局，展开行草选项也不需要滚动。画布显示尺寸随窗口缩放，内部仍为400像素，评分不受布局变化影响。已检查1366×768开场、1024×600制卡与545×665展开行草选项的布局和按钮边界。

制卡灵光随真实契合度变化：有效墨迹先显示护持；覆盖20%、准确60%时金纹渐起；覆盖50%、准确70%时开启双层金边、祥云与游动金光的「宝光出世」。空白、单点和漫墨不触发，重写后清空。灵光为画布之外的装饰层，不影响评分、书写输入或保存的笔迹；减少动态效果偏好下显示静态金纹。

## 星级与品质

参考《卡徒》公开作品介绍中的一至七星分类，具体文道含义及玩法为本项目原创设计。[作品介绍](https://wapbaike.baidu.com/item/卡徒/3762766)。星级代表卡片结构与能力层级，品质表示本次制卡完成度；一星完美仍是一星卡。

| 星级 | 名称 | 设计含义 | 当前范围 |
| --- | --- | --- | --- |
| 一星 | 字形 | 单字基础构纹 | 新手自制卡 |
| 二星 | 笔势 | 笔势带来基础效果强化 | 行草试炼达标自制卡 |
| 三星 | 复纹 | 多重构纹与封存术式 | 长者一次性赠卡 |
| 四星 | 成词 | 双字组合与语义联动 | 后续设计 |
| 五星 | 立意 | 意境与条件效果 | 后续设计 |
| 六星 | 成章 | 多卡章节组合 | 后续设计 |
| 七星 | 传道 | 核心规则与传承能力 | 后续设计 |

新手有长者护持，有效书写即可成为一星「完美」：至少160个墨像素、笔迹跨度48像素，且不能触发漫墨判定。这是刻意宽松的教学规则，不是汉字识别。新手护持只加宽笔锋，不替玩家盖章或自动描字。

制卡不提供书体选择或引笔开关，玩家直接落笔。系统同时对照基础字形与已有行草笔势范本。覆盖率至少50%、准确率至少70%时，获得二星「逸品」；未达标仍可由长者护持完成一星完美。新手默认加宽鼠标笔锋，界面只保留重写、确认成卡与暂收笔案。当前没有任意草书、隶书或其他字体的自动识别；扩展书体需补充相应范本与验证规则。

一星火：4伤害、2灼痕；二星火：6伤害、3灼痕。一星刀：7伤害；二星刀：10伤害。刀额外引爆已有灼痕。卡面说明随星级同步更新。

## 保存与验证

书写中不显示星级和完美评价，仅呈现墨路与宝光反馈。金边、卡面及卡背按覆盖与准确逐级显形，护持成卡不等同于完整宝光；空白、单点及漫墨不触发。确认成卡后弹出独立落印结果，展示真实笔迹、星级与品质，收下后继续下一步。

教学主画面只显示当前阶段和一句操作引导；卡面显示费用、星级品质与简明效果，完整规则可在牌册查看。卡阶说明移入菜单，详细战报保留无障碍播报但不占主画面。制卡只保留当前字、两卡进度、效果、材料和成卡反馈。

v5存档兼容读取v4，新增制卡期限、废纸锁定与续墨香使用状态，并保留真实墨迹、星级、品质、书体、燃尽赠卡、制卡进度、草稿、牌堆顺序与待执行敌方行动。服务端不可用时仍使用本机存档。v3原型不直接迁移，提示重开；旧版书写战斗保留在 legacy.html。

纯规则测试覆盖赠卡顺序与永久燃尽、两次固定制卡、材料防重复扣除、墨迹保存、品质判定、二星效果、草稿与敌方行动恢复及非法存档。浏览器实际验证了两次手写、行草二星、草稿恢复和自制卡进入实战；没有覆盖玩家已有存档来进行测试。

## 限时显形与废纸

新手火卡35秒、刀卡25秒，各有10秒教学护持；第一笔开始计时，重写不续时，暂收或后台继续计时。每张卡赠一次续墨香，加15秒，失败重新铺纸不返还道具。有效覆盖20%、准确60%显金纹；覆盖50%、准确70%显完整画意。已凝金纹后大片偏墨导致准确下降，或漫墨，可锁定成废纸；轻微失笔只退光。到期使用当前真实笔迹结算，合格自动落印，不合格废纸；失败不扣纸墨，可重新铺纸开启新尝试。实现与后续道具提案见 [显形设计](craft-manifestation-design.md)。

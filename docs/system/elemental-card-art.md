# 火水字卡题材画谱

物象本身提供不同尺度与意境，不把所有火卡画成同一种火焰，也不把水卡全部画成蓝色水纹。每张独立生成；同字术法未来可以选择不同题材配方，当前仅扩展美术。

资源使用内置 imagegen，位于 src/assets/cards/；完整提示见 [生成提示](elemental-art-prompts.md)。保持绢纸、水墨与矿物设色；大物象通过远小建筑与人物表现尺度，具体物体具有各自环境，中心薄雾便于叠放亲笔字。火柴、晶球和龙宫属于游戏题材创作，不当作文物复刻。

配置 faceArtByStar 仅决定同一火卡成卡后使用哪幅图，星级仍控制边框和卡背。成卡正面、手牌与牌册保持相同资源；水系与其余题材只在画谱预览，没有加入新技能、费用或数值。画谱入口保持在菜单内，教程不新增选择项。

# 制卡显形与废纸演出提案 v0.1

状态：新手关已实现首版显形、废纸、配方限时及每卡一次续墨香。定息符、长明砚与完整分段崩毁音画仍为后续提案。适用于首页亲笔制卡，替换当前有效笔迹立即触发完整宝光的表现。现行星级、数值、材料与存档规则暂不改变；下述失败锁定规则需要随实现一起更新教学说明与测试。

## 核心体验

玩家落笔，让一张朴素宣纸逐渐显出精美字卡。金边沿纸缘长出，画意在纸纤维下浮现，背纹透过纸面若隐若现。越接近完成，画意越完整、声音越收束；最后一次严重失笔可以让整张准成品失去灵性，塌回皱裂废纸。

宝光表示当前成卡潜力，落印才表示成功。书写中不提前显示「完美」、星级或成功文案。画意采用当前配方和可达星级的已有资源，不用高星卡背暗示玩家能获得未开放的卡阶。

## 构图与显形

制卡仅保留一个400×400书写画布。卡面画意与卡背暗纹作为不接收输入的装饰层，直接在同一纸面边缘渐显；中央留白让真实墨迹与字谱清楚可辨。金边、洇墨、折痕与破损均作用于这张纸。右侧只显示时间、道具、配方说明和操作，不另设卡牌预览框。正式成卡后保留既有翻牌结果。

| 状态 | 纸与金边 | 卡面、卡背 | 声音与短文案 |
| --- | --- | --- | --- |
| 静纸 | 温白宣纸，细纤维，无金色 | 只有空白卡胚 | 纸墨轻响；「静候落墨」 |
| 墨路初凝 | 墨迹附近微光，纸缘少量金点 | 画意局部像水印般浮现，背纹极淡 | 一声低弦；「墨路初凝」 |
| 金纹渐起 | 金线分段沿边生长，不一次包围 | 卡面渐清，背纹间歇浮现 | 墨声带细金属泛音；「金纹渐起」 |
| 画意将成 | 双层金边逐步闭合，少量金尘聚拢 | 精致卡面接近完整，背缘与纹章清楚 | 持续轻鸣；「画意将成」 |
| 待印 | 金边仍留一道缺口，亮度缓慢呼吸 | 成品可辨，印章为空，纸仍未定形 | 抬笔轻磬；「收笔可落印」 |
| 墨路失稳 | 出错附近洇墨，金边缺口扩大 | 画意褪色，背纹错位，局部折线浮现 | 轻鸣走音；「墨势散了，留神收笔」 |
| 废纸 | 金线断裂、褪为暗赭色，纸张皱缩、破边 | 卡面被洇墨遮散，背纹消失；保留原笔迹 | 断弦接揉纸声；「墨路已断，此纸难成」 |

## 进度与失误判定

显形同时看有效覆盖与准确程度。准确但尚未写全，只显局部金纹；大面积乱涂不能靠覆盖堆出宝光。基础字形和已支持行草范本使用一致的可达逻辑，沿用现有范本范围，不声称识别任意书法。

建议以有效覆盖控制显形进度，以准确程度控制光泽和稳定度。候选起点：覆盖20%、准确60%进入金纹阶段；覆盖50%、准确70%进入画意阶段。待印要求通过对应成卡规则，并有足够完整的覆盖。具体阈值需以火、刀真实鼠标与触控书写样本校准，不能直接照搬旧战斗评分。

笔落下时约每100毫秒更新显形，轻微平滑；普通质量下降让光泽自然回落。每次落笔记录前一笔的评分快照，并单独统计本笔新增墨迹的有效比例、出界面积与覆盖增益。重复涂抹不累计显形奖励。不能仅用全字总分判断最后一笔：此前好墨迹可能掩盖本笔失误。

严重失笔的候选条件为：已有画意阶段的基础，本笔具有足够长度或新增面积，且大部分新增墨迹偏离所有支持范本，并让整体准确度明显下跌；漫墨也可直接触发失败。短点、轻微偏移、抬笔抖动和输入取消不得触发崩毁。具体最小面积与跌幅列为实现前待校准项。

书写过程中先展示失稳预兆，正常抬笔后确认崩毁。系统没有可靠笔顺识别，因此不宣称知道「最后一笔」：任意后续严重失笔都可以毁掉准成品，玩家亲自感受到收笔风险。触发崩毁后锁定本次尝试，继续补画不能重新点亮，必须点击重写。失败不扣材料、不生成卡实例；不新增撤销按钮。书写采用下述配方时限。

## 制卡时限与时间道具

每张配方定义基础书写时限，进入笔案时显示「限时制卡 · 余时 XX 秒」。阅读配方和观察字谱不计时，第一笔落下开始倒计时。不同字的笔画数量、构纹复杂度和材料特性共同决定时限；星级提高也应给予相应书写时间，不能简单规定高星越难、时间越短。

首轮原型建议「火」35秒、「刀」25秒，复杂多笔画卡可从45—60秒起调。这些是待实测数值，不是已经验证的平衡。首次教学额外给予10秒长者护持，明示加时；正式配方在制作前列明时间，避免开始后突然发现规则。

倒计时是一轮尝试的预算：重写清空墨迹但不重置余时。暂收笔案、打开菜单、切换浏览器页面及刷新不暂停计时，重新打开时先核对期限；即便页面后台没有执行定时器，也按到期时间结算。失败或本轮到期后，可显式点击「重新铺纸」开启下一次完整尝试，沿用当前教学失败不扣材料的规则。

| 余时 | 演出与提示 |
| --- | --- |
| 常态 | 清楚的秒数及细线沙漏，声音保持安静 |
| 剩余25% | 沙漏转暗赭色，轻声提示「墨时将尽」，纸缘光泽开始收紧 |
| 最后5秒 | 显示醒目的整数倒计时，每秒一次轻木声；金边向缺口聚拢，画意仍由真实质量决定 |
| 到期 | 停止接收新墨迹，收住当前笔段，按当前笔迹执行最终结算 |

手动「确认成卡」和超时使用同一套最终规则：满足成卡条件且未崩毁，自动落印成功；有效笔迹但未达标，出现「墨时已尽，字卡未成」并播放失灵皱纸演出；空白直接提示「尚未落墨」，不播放盛大崩毁。教学护持仍可接受普通有效笔迹的一星卡，超时不会额外放宽规则。最后一秒的严重失笔优先结算失败，不以此前最高质量保底。到期正在落笔时，截止后输入不计入结果。

成功、失败及超时结算各只能执行一次，防止确认按钮与到期同时触发导致重复成卡或扣料。时间到期不直接把失败纸加入牌组。

时间道具先作为后续道具系统的配方接口，未获得的道具不在教学中凭空提供：

- 「续墨香」：使用后立即增加15秒，可在书写中使用；本轮最多一次，不能挽回已到期或崩毁的纸。
- 「定息符」：暂停书写时钟8秒；暂停期间允许落笔，纸边呈静止的青色符纹，结束后继续倒计时。本轮最多一次。
- 「长明砚」：后续稀有道具候选，开始前使用，使本次尝试不限时；笔迹失误仍可崩毁。

道具槽固定在倒计时旁，展示持有数量、效果和使用快捷键，使用不弹确认框、不打断笔势。只有实际成功生效才消耗道具；道具效果、次数和剩余数量一起保存，重写不返还已使用道具。道具秒数是候选值，待道具系统与经济设计确定后校准。

## 崩毁演出

一次完整崩毁约1.2秒，保留局部到整体的因果：

1. 0—180毫秒：最后失笔处出现暗色墨晕，金鸣骤停，纸短暂静住。
2. 180—450毫秒：细裂从失笔附近蔓延到纸缘，金线依次断开，碎金向内落。
3. 450—850毫秒：画意和背纹被墨雾吞没，纸面出现三至五道折痕，纸角卷曲，边缘缺损。
4. 850—1200毫秒：纸轻微塌缩成皱巴巴的废纸，落下少量纸屑，显示失败文案和重写入口。

废纸应当仍是一张可辨认、留下玩家笔迹的纸，不揉成遮掉字迹的球。主色是灰黄纸与墨黑，破损位置围绕实际失笔。第一次失败由长者简短解释：「末笔散了，重铺一纸便是。」重写时旧纸滑出，新纸铺入，全部显形进度清零。

成功落印与之对照：缺口闭合、朱印落下、一次清磬、翻背揭面，约0.8—1.1秒。失败与成功都不强制长停顿，动画结束后保留结果供玩家观看。

## 教学与直播观感

首次进入笔案用一句话告知：「落笔开始计时，重写不续时；字未落印，宝光未定。」失败时另提示「本次未耗纸墨，可重新铺纸」。现有教学护持仍提供普通有效笔迹的一星成卡退路，但不能把所有有效墨迹提前表现成完整金卡。严重失笔的废纸结果需要覆写护持接受逻辑，避免出现废纸仍能确认成卡的矛盾。

直播悬念来自可见的积累、失稳预兆和收笔结果。即使关闭语音、没有百分比数字，观众也应能从金边闭合程度和画意清晰度读懂「快成了」。不加入随机炸卡、假成功提示或预录回放。未定卡和废纸结果留在原位置，让镜头前的成功与失败形成明显对照。

## 实现边界与验收

评分只读取原始透明墨迹层；金边、卡画、裂纹和折痕必须在独立装饰层，不能烘焙进评分输入或保存的墨迹PNG。显形状态由当前笔迹推导；已锁定失败及必要笔段统计需要纳入草稿保存，关闭、重开与读取存档都不能洗掉失败状态。恢复旧草稿时以完整墨迹重新评估，缺少笔段记录不得虚构最后失笔。

时间参数放在配方数据中，不分散硬编码到界面逻辑。草稿保存尝试状态、开始时间、到期时间、道具加时及暂停区间，升级存档版本并保留迁移；尚未开始的旧草稿首次继续落笔才启动新时限。当前单机原型采用本机时钟恢复期限，不能承诺防改系统时间作弊。后台到期但界面未打开时仅保存待展示结果，不抢播语音；重新打开展示结算。

减少动态效果时，以静态金纹、暗裂和皱纸替代粒子、倾转与塌缩；状态文字通过现有无障碍区域低频播报，避免每个采样点播报。装饰层不接收指针事件，写字区域不因纸张变形而移动，按钮仍可通过键盘操作。

验证应覆盖：逐笔显形、正常收笔、轻微偏笔退光、准成品严重失笔崩毁、漫墨、空白和单点、重写清空、行草范本、输入取消、关闭恢复及存档恢复。补充不同配方时限、首笔启动、重写不续时、最后一笔截止、超时成功/失败/空白、后台与刷新到期、手动确认与超时竞态、道具加时/暂停/不限时和道具保存。确认失败不扣材料，成卡只扣一次；显形与最终等级不矛盾；窄屏保持一屏，所有特效不污染真实笔迹。

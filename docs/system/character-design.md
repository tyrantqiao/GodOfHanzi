# 沈砚角色与状态表现

## 形象识别

沈砚是年轻的文道制卡师：束起的黑发、青绿外袍、竹纹米白内衣、朱红旧围巾、腰间玉饰与长笔。面容、服饰和饰物在不同姿态中保持一致。整体使用细笔人物与水墨衣纹，低饱和青绿为主，朱红作为少量识别色，不使用铠甲或夸张光翼。

## 状态层

束缚：受困立绘 + 脚下淡青薄霜 + 小型「藤蔓缠身」标记。施法后切换迎战立绘，薄霜随火光消散，短暂反馈「束缚已解」。保留原有火刀出招与敌人退场动画。

后续寒蚀可用衣缘薄霜和冷色脚光；恐惧可用短时墨影和呼吸节奏；受伤另备扶臂姿态。后三项仅为设计方向，本次不加入新的战斗状态或数值规则。

# 《汉字成圣》浩然正气线故事背景与主线 v0.1

## 1. 文档用途

本文档用于沉淀《汉字成圣》的第一条主线剧本：文人出身，走浩然正气，保家卫国，除妖降魔。

这条线是游戏最先实现、最适合新手理解的主线。它不急着进入后期律法、戒律和现代文明规则，而是先让玩家体验“读书人也能拔剑守城，写字也能斩妖护民”的爽感与责任感。

## 2. 核心主题

### 2.1 主题句

天地寒冬，人心未冷；妖魔压境，文气不绝。

### 2.2 情绪曲线

- 开局：惊醒、无助、被救。
- 前期：学字、识文、第一次守住别人。
- 中期：见乱世、见牺牲、见文人并非只会空谈。
- 中后期：导师离去，主角独自承担边境与百姓。
- 后期：主角以自己的文章、诗意和浩然气重建一方文脉。
- 终局：不是单纯打赢妖王，而是让“人族仍值得被守护”成为天地认可的道理。

## 3. 世界状态

### 3.1 寒冬纪元

寒冬纪元已经持续数十年。它不是单纯的气候灾害，而是世界秩序衰败后的综合灾变：

- 天地灵机偏寒，妖物更容易吞噬生灵。
- 边境粮食减产，战乱和流民不断。
- 圣人遗迹逐渐失效，古碑、城墙、文庙的力量正在衰退。
- 人心动摇，很多读书人开始怀疑文道是否还能救世。

### 3.2 无皇之国

主角醒来的国家暂称“承圣国”。此国没有皇帝，靠三类力量维持秩序：

- 文院：培养文人，修复典籍，维护文脉。
- 镇妖军：驻守边境，负责实际作战。
- 圣碑体系：过往圣人留下的碑文、律令、阵线和城防。

承圣国的政治结构不是铁板一块。文院重传承，军府重现实，地方城主重自保，百姓只想活过下一个冬天。主角的浩然正气线，就是在这些矛盾中一步步回答：读书人的力量到底该为谁而用。

## 4. 主角与导师

### 4.1 主角定位

主角是来自地球的异乡魂，醒来后依附在一名低阶文人或文院学徒身上。为了让“文人出身”更清晰，建议主角在异界的身份设为：

- 边境书院的落榜学徒。
- 家境普通，识字但未真正入品。
- 原身曾想靠科考或文院改变命运，却死于妖祸或寒灾。
- 地球灵魂醒来后，继承原身的身体和残缺记忆，同时带来地球文明中的汉字、诗文、历史与精神力量。

主角的核心矛盾：

- 他不是天生圣人，一开始只是想活下去。
- 他懂很多地球文字与典故，却必须在异界血火里证明这些东西真的有用。
- 他要从“借用前人文章”成长为“写出自己的道”。

### 4.2 导师定位

导师暂称“执笔人”。他是前期救下主角的人，也是玩家理解世界的第一双眼睛。

导师功能：

- 教主角低品文人如何写字成术。
- 解释寒冬纪元、九品体系、圣碑和妖祸。
- 在前期战斗中作为辅助角色。
- 用自己的离去完成主角的成人礼。

导师离去建议放在“五品成章境”章节末。理由：

- 前四个品级是学习阶段，导师存在合理。
- 五品“成章”意味着主角必须从单字、短句成长为能独立成篇的人。
- 导师离去后，四品“文胆境”才真正成立：主角必须在恐惧、孤独、责任中生出文胆。

导师离去方式待确认，可选：

- 牺牲：为守城或救百姓写尽最后一字。
- 失踪：进入寒渊或妖域，为后续剧情埋伏笔。
- 背负罪责离队：导师为了执行更残酷的选择离开主角。
- 被高层力量带走：牵出文院内部、圣碑体系或古圣遗留阴谋。

## 6. 分卷主线

### 6.1 第一卷：雪林醒魂

对应境界：九品开窍境。

主线目标：活下来，学会第一个字。

故事梗概：

主角在雪林中醒来，被霜藤妖缠住。技能槽为空，身体无法移动。导师赶到，写下“刀！”斩断藤蔓。主角被带往边境小村，途中第一次接触文人九品、寒冬纪元和妖祸。

关键剧情：

- 霜藤妖袭击，主角开局无力。
- 导师以“刀”救场。
- 主角第一次书写“斩”或“静”。
- 主角发现自己脑海中的地球文字能与此界文气共鸣。
- 进入青崖村，看到寒冬下的普通人生活。

核心敌人：

- 霜藤妖。
- 寒鸦妖。
- 被寒气污染的野兽。

能力解锁：

- 汉字：刀、斩、静、定。
- 基础机制：行动条、书写底板、精神槽、状态解除。

卷尾事件：

村口圣碑开裂，碑中残字认出主角身上的“异乡文气”。主角被建议前往边境文院。

### 6.2 第二卷：边村夜火

对应境界：八品聚气境。

主线目标：第一次主动守护他人。

故事梗概：

青崖村被妖潮盯上。镇妖军兵力不足，文院援手未到。导师本可带主角离开，但主角见到老人、孩童、伤兵和藏书阁中的残卷后，决定留下守夜。

关键剧情：

- 主角学习文气凝聚，能承载更多字。
- 村民对文人既敬又怨，认为读书人救不了粮荒。
- 主角用“火”“守”“明”等字帮助巡夜和防守。
- 夜战中第一次通过短句鼓舞己方。

核心敌人：

- 寒鸦妖群。
- 雪尸。
- 小型妖潮。

能力解锁：

- 汉字：守、火、明、风、盾。
- 短句：可使用一句简单经典文本作为战斗鼓舞。

卷尾事件：

青崖村守住，但粮仓半毁。主角明白“赢一场战斗”和“救一个地方”不是同一件事。

### 6.3 第三卷：入院试文

对应境界：七品通文境。

主线目标：进入文院，理解诗文不是背诵，而是通其精神。

故事梗概：

主角进入暂称“青麓文院”的边境分院。这里聚集着读书人、寒门学子、世家子弟和战场退下来的残疾文士。主角的地球诗文让文院震惊，但也引发质疑：借来的文字，算不算自己的道？

关键剧情：

- 入院测试要求以字破妖、以文答问。
- 主角第一次使用古诗句能力。
- 文院内部有人怀疑主角是妖物伪装或异端。
- 失控文徒被寒意污染，证明文气也会反噬人心。

核心敌人：

- 失控文徒。
- 伪装成学生的魇妖。
- 文院试炼中的残影妖。

能力解锁：

- 汉字：破、镇、清、醒、疾。
- 诗文：豪迈类、守志类、清心类文本各一条。

卷尾事件：

主角通过文院试文，但没有被立刻接纳。他被派往北境前线，用真正的战场证明自己的文。

### 6.4 第四卷：北境烽烟

对应境界：六品立意境。

主线目标：立下自己的第一道文意。

故事梗概：

北境战线崩坏，难民南逃。主角跟随导师和镇妖军进入前线，第一次看到城墙外堆积的雪尸、妖兽和冻死的百姓。他必须决定自己的文字是为了求胜、求名，还是为了守人。

关键剧情：

- 主角见到镇妖军的残酷现实。
- 文院与军府争论：救难民还是守关口。
- 主角在战场上用诗文稳住溃兵。
- 第一次出现“浩然正气”的明确觉醒。

核心敌人：

- 雪尸将。
- 食心妖。
- 妖化逃兵。

能力解锁：

- 汉字：勇、义、归、阵、止。
- 机制：文意选择。玩家可偏豪迈、忧民、守义、明志等方向。

卷尾事件：

主角立下第一道文意：“我之文，不为自证，只为此地仍有人敢守。”

### 6.5 第五卷：断桥留章

对应境界：五品成章境。

主线目标：从单字短句成长为能写成一篇完整文章的人。

故事梗概：

妖潮截断边境退路，大量百姓被困在断桥两侧。导师发现圣碑阵线已经无法支撑，必须有人以自身文气补完残章。主角还未成熟，导师选择替他完成这一笔。

关键剧情：

- 主角学习文章段落类技能。
- 妖潮围桥，百姓、军卒、文院学生混在一起。
- 导师展示真正的成章境：不是写出华丽文字，而是让文字承担后果。
- 导师离去，主角第一次失去依靠。

核心敌人：

- 霜骨巨妖。
- 妖潮指挥者。
- 寒渊裂隙。

能力解锁：

- 汉字：生、桥、断、归、燃。
- 文章技能：短篇战场檄文或守城文。

卷尾事件：

导师留下残章，主角继承其笔。断桥之后，主角不再是被救的学生，而是必须救人的文人。

### 6.6 第六卷：孤城问胆

对应境界：四品文胆境。

主线目标：在恐惧中生出文胆。

故事梗概：

导师离去后，主角被派往一座孤城。城中人心涣散，妖物不急着攻城，而是用幻境、谣言和恐惧瓦解守军。主角必须在无人替他兜底的情况下，守住城和自己的心。

关键剧情：

- 主角因导师离去出现精神负面状态。
- 妖物以幻境模拟导师责问主角。
- 城中出现投降派、逃亡派、死守派。
- 主角以“文胆”破幻，第一次真正成为一城精神支柱。

核心敌人：

- 惑心魇。
- 伪圣碑幻影。
- 寒梦妖。

能力解锁：

- 汉字：胆、诚、醒、照、拒。
- 诗文：守志、抗惧、明心类经典文本。

卷尾事件：

主角守住孤城，文胆成形。他明白浩然正气不是不会害怕，而是害怕时仍然知道什么不能退。

### 6.7 第七卷：山河入心

对应境界：三品文心境。

主线目标：形成主角自己的文心。

故事梗概：

主角走过多座城、多片战场和多种人心。他见过豪迈者、忧民者、忠义者、逃亡者、背叛者，也见过妖物并非全都只有杀戮本能。文心境要求他回答：他的文道到底是什么？

关键剧情：

- 主角重访前几卷地点，看到自己的选择留下了后果。
- 文院高层希望他成为宣传旗帜。
- 军府希望他成为战争武器。
- 百姓只希望他继续活着。
- 主角拒绝只做某一方工具，确立“山河入心，万民在文”的路线。

核心敌人：

- 妖王前锋。
- 腐化文官。
- 伪装成人的高阶妖族。

能力解锁：

- 汉字：民、山、河、心、志。
- 机制：文心流派。玩家可根据常用诗文和汉字形成偏向。

卷尾事件：

主角写出第一篇真正属于自己的文章，不再只是借用地球经典，而是把地球文明和异界山河熔成自己的文心。

### 6.8 第八卷：重修圣碑

对应境界：二品著道境。

主线目标：重建正在崩塌的文脉体系。

故事梗概：

圣碑体系大面积失效，承圣国边境即将全线崩溃。主角发现旧圣碑只记录了旧时代的秩序，却无法回应寒冬纪元的新问题。他必须著道，不是推翻前人，而是在前人的碑上补出新篇。

关键剧情：

- 主角调查圣碑失效原因。
- 旧文院保守派反对修改圣人遗留。
- 主角证明圣人精神不是照抄旧字，而是守住其救人之意。
- 后期律法分支可在本卷开始埋入正式解锁条件。

核心敌人：

- 寒渊大妖。
- 圣碑蛀灵。
- 文院保守派制造的试炼。

能力解锁：

- 汉字：碑、续、道、衡、正。
- 文章技能：可生成持续场地效果。
- 可选系统：律法分支开始解锁。

卷尾事件：

主角完成新碑初稿，天地承认其“著道”资格。妖族意识到主角已不只是战场文人，而是可能改变时代的人。

### 6.9 第九卷：寒天成圣

对应境界：一品半圣境。

主线目标：在寒冬纪元最深处，完成浩然正气线的终局回答。

故事梗概：

妖祸总源头显现。寒冬不是单一妖王造成，而是天地、人心、旧秩序和妖族怨气共同积累的结果。终战不只是杀死敌人，也要让新文道撑住世界回暖的第一缕气。

关键剧情：

- 承圣国各地防线同时崩溃。
- 主角重召前几卷救过的人、写过的字、立过的意。
- 导师残章回响，帮助主角补完最后一篇文。
- 主角面对终极问题：若圣人必须牺牲自己换天下太平，是否还愿意写下最后一字？

核心敌人：

- 寒天妖主。
- 寒冬纪元本身的意志化身。
- 被污染的旧圣残影。

能力解锁：

- 汉字：圣、春、天、人、正。
- 终局技能：浩然长文。由玩家一路收集、理解和书写过的字句共同构成。

结局方向：

- 普通结局：击退寒冬，边境回暖，主角成为半圣。
- 真结局：主角不以个人封圣为终点，而是把文道还给天下读书人，开启“人人可拾字，人人可守心”的新时代。

## 7. 浩然正气线的玩法落点

### 7.1 主线能力风格

浩然正气线强调：

- 正面战斗。
- 抗恐惧、抗魅惑、抗污染。
- 保护队友与平民。
- 诗文鼓舞。
- 大范围清场。
- 在低血量或守城场景中越战越强。

### 7.2 与律法分支的关系

浩然正气线是情感、信念和文气的主干。律法分支是中后期从文明规则中长出的分支。

二者区别：

- 浩然正气问“我为何而战”。
- 律法分支问“力量应该被什么约束”。

第一条主线应先把浩然正气讲完整，律法只在后期作为新问题、新系统、新流派出现。

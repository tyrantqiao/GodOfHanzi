# 安卓版本

支持 Android 9 及以上，使用系统 Android WebView 加载 APK 内的完整游戏资源，首次启动无需网络。系统 WebView 应保持更新，以支持原生网页的对话框与样式。爬塔与制卡练习均可进入；本地存档使用原有 localStorage，覆盖安装保留，卸载会删除。安卓没有本地 Node 服务，服务端存档及 Kokoro 语音不可用；游戏会使用本地存档和既有静音回退。

启动后查询 GitHub 最新正式 Release，读取 android-update.json；版本号变大才后台自动下载 GodOfHanzi.apk。下载失败不影响游戏。安装前验证 SHA-256、应用包名、versionCode 和当前安装包签名，提示保存进度，随后调用系统安装器。首次安装更新须允许本应用“安装未知应用”，每次安装须系统确认，不支持静默安装。

## 发布

固定包名 com.godofhanzi.game；签名别名 hanzi。GitHub Secrets 保存 ANDROID_KEYSTORE_BASE64、ANDROID_STORE_PASSWORD、ANDROID_KEY_PASSWORD。本地 .android-private/ 中的签名材料必须私下备份，不得提交。丢失签名无法覆盖更新已有安装。

修改 android/version.json，versionCode 必须大于所有已发布版本，versionName 与标签一致。提交游戏与安卓工程后推送 android-v版本名称 标签，Android Release 工作流运行游戏测试、打包离线资源、构建已签名 APK，并发布 APK 和更新清单。workflow_dispatch 可仅构建并下载 artifact。发布到 Release 的名称必须保持 GodOfHanzi.apk 和 android-update.json。

本地开发需 JDK17、Android SDK35、Gradle8.9；执行 node scripts/package-android.mjs，再设置签名环境变量并执行 gradle -p android assembleRelease。不引入网页框架或 npm 运行依赖。

## 验证

CI 验证全部游戏纯规则测试及安卓编译。真机验收：安装首版；飞行模式下新局、路线、战斗、奇遇书写、奖励、笔斋、登顶/败北；保存后强退重启恢复；制卡画布触摸不滚动；旋转、返回键及导航到教学页；联网启动新版下载；拒绝安装权限/取消安装仍可游玩；允许权限后覆盖安装并恢复旧存档。以同签名 versionCode+1 的版本验证更新；损坏 APK 或签名不符应拒绝安装。此流程不能以编译通过替代真机验证。

自动验收工作流 Android Smoke 使用实际 Release APK，断网进入首层奇遇、保存并重启恢复，再从同签名旧版本联网启动，让应用自行检查、下载并通过系统安装器覆盖更新，验证版本递增与存档保留。测试报告与截图保存在 Actions artifact。未连接实体安卓设备，触控笔手感和不同厂商安装器仍需真机验收。

2026-10-07 验收通过：82 项游戏单元测试；Android 15 模拟器实际安装 Release APK，离线进入李白奇遇、保存后强退重启并读档；从 v0.1.1 启动自动下载 v0.1.3，通过校验并在系统安装器确认覆盖安装；打开新版恢复原存档；新一局确认框生效，再次读档恢复原奇遇。记录：https://github.com/tyrantqiao/GodOfHanzi/actions/runs/37602393936 。当前最新正式 APK 为 android-v0.1.3 / versionCode 3，后续发布须从 versionCode 4 起递增。

### 全面屏与选项布局调整（2026-10-07）

安卓容器改为沉浸式横屏，隐藏状态栏与导航栏，边缘滑动可临时唤出。Android 9 起允许延伸到挖孔区域，原生容器只为挖孔与必要手势区留出安全边距；重新获得窗口焦点时恢复全屏。网页主棋盘按容器实际高度布局，避免安全区叠加后超出视口。

奇遇改为左侧故事、右侧行动。故事可展开，正文与反馈独立滚动，不推走选项；奖励卡根据屏幕高度压缩画意，保留效果与跳过按钮。大量删牌／强化候选采用横向滑动。视觉采用墨青导航、暖白宣纸、朱砂主操作，攻击／防守／术法保留独立色标。

已通过82项游戏规则测试，以及800×360、960×540、1000×440桌面浏览器横屏检查（首遇选项、展开故事、奖励与跳过）。OPPO Find X8 Ultra 的挖孔、双向横屏、手势唤出系统栏及切回游戏仍需真机检查；浏览器尺寸验证不能代替 ColorOS 真机验收。

本轮本地 Gradle 离线 assembleDebug 编译通过，安卓离线资源已重新生成。未发布正式更新，未进行 OPPO 真机安装验收。

### 启动主菜单与轻量工具栏

进入游戏先显示主菜单：开始试炼、继续存档、制卡练习；首次开始后仍保留开局卡组提示。游戏中可从试炼菜单返回主菜单，并通过“返回当前试炼”恢复本次未退出的进度。返回主菜单不自动写存档，退出应用前仍须保存。继续存档成功后进入战场，失败时在主菜单说明原因。

顶部改为36px工具栏，牌册、凝式与菜单使用SVG图标，保留中文无障碍名称。已验证800×360、960×540、1000×440下的启动、牌册打开、返回当前试炼、无存档提示与本地读档；82项规则测试通过。安卓冒烟脚本同步新增主菜单入口及图标菜单导航。

### 场景与半透明行动层

参考用户提供的卡牌爬塔界面，主战场改为背景优先的透明行动层：移除中央大块宣纸底板，奇遇选项以半透明墨青条目显示图标、行动与简短效果。生命代价、候选字与强化／制卡结果直接显示，触屏无需悬浮获取必要决策信息。左侧展示故事摘要，全文可展开；奖励和跳过保留原来的单屏布局。

顶部用图标加数字显示生命、层数、牌组，敌方生命／意图／护甲／灼痕与玩家文气／格挡／蓄势采用同一图标体系。tower-ui.js 仅负责展示与提示，不参与规则结算。按钮、字卡、状态支持鼠标悬浮和键盘焦点提示，Escape关闭；点击、滚动、切换面板与窗口尺寸变化会清理提示。弹窗提示放入对应原生dialog以保持顶层可见，触屏点击不额外弹出悬浮层。

已验证800×360、960×540、1000×440下的选项可见、悬浮／键盘焦点／Escape、弹窗提示层级、奖励跳过和完整出牌回合，浏览器触屏模拟验证直接选择与无残留提示。OPPO真机仍待验收。

## 更新断点续传

设置中的版本更新提供下载进度、暂停、继续下载和安装按钮，参考 nextStep 更新页的状态管理。版本清单和下载文件保存在应用私有 files/updates 中，按 versionCode 与 SHA-256 区分安装包。断网、暂停或进程退出后保留 update.part，重试发送 HTTP Range；服务端不支持范围时从头下载，范围不符时拒绝追加。新版本替换旧断点，完整下载后验证 SHA-256、包名、版本和签名；再次安装前重新校验。暂停状态跨重启保留，已下载安装包可稍后安装。新版发布清单增加 size，旧清单仍兼容。

验收补充：下载中暂停并继续、断网重试、强退重开、返回设置恢复进度；服务端忽略 Range、错误 Content-Range、损坏包与版本切换；取消安装后再次安装。

验证命令：npm test；配置 JAVA_HOME 后执行 npm run test:android-update；node scripts/package-android.mjs 后执行 Gradle assembleDebug。断点下载测试涵盖暂停恢复、200 回退、错误范围、416、网络中断、完整包复用和大小限制。

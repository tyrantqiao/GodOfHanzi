# 奇遇库 v0.3

共30个已接入事件。古代人物的对白均为游戏架空创作，挽词为本游戏原创选项，没有正误／道德评分。历史人物名单：李白、杜甫、苏轼、李清照、陶渊明、王维、岳飞、项羽、屈原、文天祥、嵇康、荆轲、王羲之、欧阳询；无近现代历史人物。孙悟空、令狐冲、萧炎为明确标识的小说彩蛋。

第一层固定月下论诗，后续按种子抽取且本局不重复。每次收获只取一张，不因为来回打开界面重复领奖。冒险的代价公开；题目有逐题解析；书写机会可取消重选、可用稳笔辅助。当前风险型冒险是选择与资源权衡，没有随机伤亡或专属战斗。数据源：data/tower-events.json。

# 《汉字成圣》汉字技能素材库 v0.1

## 1. 文档用途

本文档用于记录可转化为游戏技能的汉字素材。每个汉字都应同时服务三件事：

- 游戏性：它在战斗中有明确效果。
- 表现力：它写出来、飞出去、命中时有视觉记忆点。
- 文化性：它能引出字义、典故、历史或汉字结构的说明。

## 3. 技能设计原则

### 3.1 一个字不要只有一种解释

汉字技能可以随品级成长产生分支：

- “火”低级是燃烧，高级可以是烽火、心火、薪火。
- “守”低级是护盾，高级可以是守城、守约、守心。
- “正”低级是净化，高级可以是正名、正道、正气。

### 3.2 简繁体可以带来差异

简体适合新手和低消耗释放。繁体或古体可以作为高阶模板：

- 斩/斬：繁体模板可提升切割效果或破甲。
- 静/靜：繁体模板可提升净化与精神稳定。
- 义/義：繁体模板可与牺牲、守护、誓约效果绑定。

### 3.3 早期不要过多高概念字

“龙”“雷”“剑”“圣”等高爽感字可以出现，但建议作为剧情奖励、隐藏字或短暂体验，不宜开局大量开放。否则玩家会跳过“刀、斩、静、守”等教学字的成长感。

## 5. 后续扩展方向

1. 扩展到第一批 100 字，覆盖攻击、防御、净化、控制、召唤、场地、探索。
2. 为每个字建立简体、繁体、楷书、行书、草书模板。
3. 为每个字补充字源说明、常见词组、历史典故和技能台词。
4. 建立高阶组合字机制，例如“风+火”“守+城”“明+心”。

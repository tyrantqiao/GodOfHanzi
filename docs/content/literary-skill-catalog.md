# 《汉字成圣》诗文典籍技能素材库 v0.1

## 1. 文档用途

本文档用于记录可转化为游戏技能的古诗、宋词、典籍、文章和汉译经典素材。

原则：

- 优先使用中国古典诗文、诸子经典、史书名句和公版文本。
- 可以使用中外经典，但必须能通过汉字表达出稳定精神内核。
- 不收录纯音译内容，不依赖外语押韵、发音或现代版权文本。
- 游戏中可以展示来源和简短说明，但说明必须谨慎，避免把演绎当史实。

## 4. 文学技能使用方式

### 4.1 标准释放

1. 玩家从句槽选择已解锁文本。
2. 游戏显示文本前半或关键句。
3. 玩家确认释放。
4. 若玩家手写最后一个关键字，获得更高倍率或额外效果。

### 4.2 探索释放

玩家也可以主动输入文本。系统匹配达到阈值后：

- 若文本在素材库中，直接解锁或临时释放。
- 若文本未入库但属于允许范围，可记录为候选素材。
- 若文本为现代版权、网络梗、纯音译或无法汉文化承载，则不进入核心技能库。

### 4.3 手写关键字

长句不要求逐字手写，重点写最后一个承力字：

- “志”：明志、抗控、文胆。
- “国”：家国、守护、牺牲。
- “人”：仁心、规则、反制。
- “正”：净化、浩然、终局。
- “新”：成长、刷新、突破。

## 5. 与浩然正气线的关系

浩然正气线优先使用以下文学精神：

- 李白式豪迈：解决“我敢不敢破局”。
- 杜甫式忧民：解决“我为何守人”。
- 诸葛亮式以身许国：解决“责任是否值得以命相托”。
- 论语、周易、大学等经典：解决“心志、修身、秩序、学习”的底层成长。

后期律法分支可以从“己所不欲，勿施于人”等规则性文本中生长出来，但不在前期抢主线表达。

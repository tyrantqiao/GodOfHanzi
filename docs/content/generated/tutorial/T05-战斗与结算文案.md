# T05 · 战斗与结算文案（8 事件 × 3 模板）

| 字段 | 内容 |
| --- | --- |
| id | T05 |
| 类别 | 战斗与结算文案 |
| 名称 | 新手关战斗日志与结算提示模板库 |
| 当前/拓展 | 拓展（当前日志仅三条：`playCard` 打出句、`endTurn` 灼痕句、`resolveEnemy` 敌袭句；本批补齐全事件并保持占位符规范） |
| 使用场景 | 战斗日志 `#log`、播报 `aria-live` 区、后续战报面板 |
| 角色 | 系统旁白（无口吻），日志体：规则信息优先、修辞简短 |
| 字数限制 | 单条模板渲染后 ≤40 字为宜 |
| 占位符 | `{cardChar}` `{cardName}` `{damage}` `{burn}` `{stacks}` `{extra}` `{enemyName}` `{intent}` `{taken}` `{energy}` —— 全部命名占位，不混用位置参数 |
| 参考 | `src/card-tutorial-core.js`（playCard/endTurn/resolveEnemy 现文案）、`data/tutorial-cards.json` enemies |
| 验收要点 | 数值口径与结算一致（引爆=每层灼痕+2；灼痕回合末按层数结算后减 1）；不虚构奖励或解锁；敌人败北表述用「击退」不用「击杀」；赠卡燃尽与自制卡入弃牌堆严格区分 |

## 1. 出牌命中

| # | 模板 |
| --- | --- |
| 1 | 打出「{cardChar}·{cardName}」，命中{enemyName}，造成{damage}伤害。 |
| 2 | 「{cardChar}」应声而落，{enemyName}受{damage}伤害。 |
| 3 | {cardName}斩中{enemyName}，气血-{damage}。 |

## 2. 附加灼痕

| 3 | 灼痕附着：现在{enemyName}有{burn}层灼痕。 |

| 3 | 「{cardName}」引燃旧痕：{stacks}层×2={extra}伤害。 |

## 5. 自制卡弃牌

| # | 模板 |
| --- | --- |
| 1 | 你的亲笔卡「{cardName}」进入弃牌堆，之后会再抽到。 |
| 2 | 「{cardName}」收势入堆，笔迹未灭，去留有时。 |
| 3 | 亲制卡不燃尽：「{cardName}」静候下一次抽取。 |

## 4/5 补充说明

- 未使用的卡留在手上（retain），不产生弃牌日志；此条为规则事实，模板不得写成「回合结束全部弃牌」。

## 6. 敌人攻击

| # | 模板 |
| --- | --- |
| 1 | {enemyName}发起攻击{intent}，你受到{taken}伤害。 |
| 2 | 藤影压顶：{enemyName}造成{intent}伤害，实受{taken}。 |
| 3 | {enemyName}攻势{intent}，气血-{taken}。 |

- 口径说明：现版日志即为「妖物攻击{intent}，受到{taken}伤害」；`{intent}` 是敌方意图值、`{taken}` 是扣格挡后的实伤，两值并存时不得混写。

## 7. 战斗胜利

| # | 模板 |
| --- | --- |
| 1 | {enemyName}被击退，战场暂归寂静。 |
| 2 | 妖势已尽：{enemyName}消散退场。 |
| 3 | 此战告捷，{enemyName}永久离开当前战场。 |

- 霜藤战用「退场」表述（现实现：击败后永久离开）；残碑战胜利直接衔接入门完成，不得写掉落/经验等未实现奖励。

## 8. 战斗失败

| # | 模板 |
| --- | --- |
| 1 | 气血耗尽，此战失守。 |
| 2 | 你被{enemyName}逼退，幸有长者护持残墨。 |
| 3 | 战败不夺卡：牌册与亲笔卡都在，重振再来。 |

- 第 2/3 条中「长者护持」「不夺卡」仅陈述现有可重开规则（重开走 `reset()`，无资源损失），不得引申为复活或补偿机制。

## 接入备注

- 现版 `run.log` 为纯字符串数组且参与存档校验（`validSave` 仅要求字符串），模板化改造需保留旧日志可读，属后续工程项。
- 灼痕逐回合结算文案（`灼痕造成{burn}伤害。`后层数-1）沿用现句，不重复建模板。

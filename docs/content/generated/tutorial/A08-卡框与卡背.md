## 现有基线（核对自 rank-1/rank-3 源文件）

- 三层结构：`#f4eedf` 纸底 → 18px 纸纹 pattern → 径向渐晕 wash → 边缘纹样组。
- 一星：灰银 `#718078` 疏竹侧影，单层细框；三星：鎏金 `#b68c3c` 对角祥云 + 双层金框 + 中央双环菱印（内含抽象井格印文）。
- 卡背：满幅中央圆环+旋转 45° 菱形+井格印，四边出榫短线。

## v2 分级方案

### 一星 · 字形（灰银，竹影）

- 纹样：两侧疏竹保留，竹节由 5 枝减为 3 枝并下移，避开中上部费用印章位；四角各加一枚 6px 银灰竹钉纹（结构层「未封」的裸框感）。
- 材料语言：未经浆洗的粗纸，框线 1.2px 单线灰银，无包角。
- 颜色：框 `#718078`，wash 灰银 0.14；纸纹透明度保持 0.09。
- 正面提示词（SVG 修改指令）：在现 `rank-1-face.svg` 基础上删除 `(38,270)` 处竹枝，四角追加 6×6 竹钉 path；不引入新色。
- 卡背提示词：保留竹纹对角与银灰封印，中央菱形缩至 r=44 让位题铭区；井格印文减为两横一竖（「字形」初学之意，抽象非字）。

### 二星 · 笔势（青蓝，沧澜）

- 纹样：上下水波纹由直排改为单向卷势（笔势「提按」的水相），左右缘各加一条 1px 断笔水线（飞白效果用 dasharray 6 4）。
- 材料语言：半熟宣，框线 1.6px 青蓝 `#4a6b78`（在灰青 `#597b79` 系内加深，保持与卡纹图鉴一致），四角加银蓝包角片。
- 卡背：水纹环带围绕中央菱印，印内井格增为三横三竖。
- 正面提示词（SVG 修改指令）：现 `rank-2-face.svg` 水波组 path 末端统一加卷钩 8px，左右缘增 dasharray 断线；框色不变。

### 三星 · 复纹（鎏金，瑞云）

- 纹样：对角祥云保留并增第二层细云（复纹=纹样叠纹），双层鎏金框已实现；四角云头包角加阴刻一线。
- 材料语言：装裱绫边感，外框 2px + 内框 1px，间距 6px；金 `#b68c3c` 不变，禁渐变金。
- 卡背：现版双环菱印+井格已是终稿基准，v2 仅在环外补四枚小云头，指向「封存术式」；长者赠卡翻牌用此背。
- 正面提示词（SVG 修改指令）：`rank-3-face.svg` 云纹组复制一份缩放 0.6、透明度 0.45 垫于原云纹下，形成叠纹。

### 品质表达（与星级正交）

- 完美：CSS 缓慢闪面（3% 亮度扫掠 6s 一次）+ 框线柔光 0.5px；逸品：柔光加强至 1px 青蓝晕。二者不改 SVG 文件，仅作用 `.card` 容器，减少动态偏好下关闭。
- 成卡前（制卡 `liveCard`）不显示星级框色，仅灰纸卡胚——与现实现一致，列为验收回归项。

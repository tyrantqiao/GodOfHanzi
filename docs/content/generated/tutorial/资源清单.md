## 交付约定

- 实际图片/音频审核产出后先放入 `pending-review/`（子目录 characters / cards / backgrounds / objects / fx），不覆盖 `src/assets/` 现有资源；接入另行进行。
- 各文件页首元数据表含 id、类别、当前/拓展、使用场景、参考路径、透明要求、推荐文件名、验收要点，满足要求文档第六节的交付格式。
- 所有「拓展建议/题材储备/后续设计」均在文中就地标注，未写成已实现功能；未确定尺寸均写为建议值。

## 规则一致性基线（生成时逐项核对）

- 数值一律取自 `data/tutorial-cards.json`：借火破霜 1费/6伤/2灼痕；借刀断藤 2费/8伤/引爆每层+2；朱砂引燃 1费/4伤/2灼痕（二星6/3）；松烟斩势 2费/7伤/引爆（二星10）；残碑战每回合3文气，敌攻6/8/10循环；霜藤不反击。
- 赠卡永久燃尽、先火后刀锁（`canPlay`）、自制卡弃牌可再抽、未用保留（retain）、失败不扣纸墨、重写不续时、火35+10秒/刀25+10秒、一星完美底线160像素/跨度48、二星阈值覆盖50%/准确70%、书写中不显示星级——全部与 `card-tutorial-core.js`、`crafting-grade.js`、`craft-session.js`、`card-ranks-and-tutorial.md` 现实现一致。
- 卡面插画不烘焙主字/数字/费用；导师笔迹与玩家笔迹分开；透明资源要求真实透明底。

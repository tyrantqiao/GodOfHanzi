规则事实核对（写台词时的硬约束）：
- 赠卡「借火破霜」（1文气）、「借刀断藤」（2文气）用后永久燃尽，不洗回牌堆。
- 霜藤战敌人不反击（attacks 为 0）；残碑战每回合 3 文气，敌人意图公开（6/8/10 循环）。
- 火施灼痕、刀引爆灼痕（每层 +2）；火未出、刀先锁：霜藤战未用「火」前不能用「刀」（`canPlay` 约束）。
- 制卡：第一笔起计时（火 35+10 秒、刀 25+10 秒），重写不续时，失败不扣纸墨。
- 自制卡用后入弃牌堆可再抽，未使用的卡回合结束留在手中（retain）。
- 书写中不显示星级与完美评价；星级只在落印结果出现。

---

## 1. 接卡

触发事件：玩家点击「接过字卡」（stage: gift → battle），两张三星赠卡入手。

| # | 台词 |
| --- | --- |
| 1 | 卡轻，墨意重。火与刀的先后，记在心上。 |
| 2 | 先接卡，再看藤。这两张能救你眼前一命。 |
| 3 | 笔迹封在卡中，用一张少一张，使完即燃。 |

## 2. 先火

触发事件：霜藤战第一回合，沈砚藤蔓缠身，手中有两张赠卡。

| # | 台词 |
| --- | --- |
| 1 | 先用「火」。烧断缠身的霜藤。 |
| 2 | 霜藤畏火。打出「借火破霜」，点燃它。 |
| 3 | 火落下去，灼痕会留在藤妖身上。 |

## 3. 接刀

触发事件：火赠卡燃尽后，手中只剩「借刀断藤」。

| # | 台词 |
| --- | --- |
| 1 | 火已烧藤，再用「刀」斩尽残缚。 |
| 2 | 「借刀断藤」引爆灼痕，一击退霜藤。 |
| 3 | 这一刀落下，赠卡的债就算还清了。 |

## 4. 赠卡燃尽

触发事件：两张赠卡先后用尽、霜藤被击退，进入制卡阶段前的过渡。

| # | 台词 |
| --- | --- |
| 1 | 赠卡燃尽，灰烬不是损失，是交接。 |
| 2 | 借来的力留不久。剩下的路，要你自己写。 |
| 3 | 老夫不能陪你每场都递卡。铺纸，磨墨。 |

## 5. 首次制卡

触发事件：首次打开笔案（stage: craft，0/2），书写「火」前。

| # | 台词 |
| --- | --- |
| 1 | 莫怕废纸，墨路有老夫护持，落笔便是。 |
| 2 | 笔一落便计时，重写不续时，笔势心里有数。 |
| 3 | 先看字帖再动笔。「火」的四笔，起落都有次序。 |

## 6. 双卡完成

触发事件：火、刀两张亲制卡均落印（stage: crafted）。

| # | 台词 |
| --- | --- |
| 1 | 火刀双成。从今往后，你的字就是你的卡。 |
| 2 | 两张卡薄，却都是你入门的字。收好。 |
| 3 | 携火刀去残碑。前面的妖，要你自己面对。 |

## 7. 自制卡再次抽回

触发事件：残碑战第 2 回合起，自制卡从弃牌堆洗回、重新抽入手中。

| # | 台词 |
| --- | --- |
| 1 | 你写的卡不会燃尽。用过，会回到牌堆。 |
| 2 | 上一回合的火又抽回来了。照旧，先火后刀。 |
| 3 | 没打完的卡留在手里，不必担心收走。 |

## 8. 文气用尽后结束回合

触发事件：残碑战中文气耗尽或玩家选择不再出牌，提示结束回合。

| # | 台词 |
| --- | --- |
| 1 | 一回合三文气。用尽了，便结束回合。 |
| 2 | 牌打不动就收手。结束回合，灼痕还会烧。 |
| 3 | 妖物的意图已经公开。算好账，再结束回合。 |

# 《汉字成圣》新手关资源生成要求

供 qwen3.8-flash 读取并分批处理。整理日期：2026-10-02。

## 一、任务与范围

为当前新手关建立可持续拓展的美术与文本资源库，输出文案、资源设计稿、绘图提示词及资源清单。美术资源如无法直接生成图片，则输出可交给图片或矢量生成工具的完整提示词，不将文字描述标记为已完成图片。

当前实际入口是 `index.html`，逻辑为 `src/card-tutorial.js` 与 `src/card-tutorial-core.js`，数据为 `data/tutorial-cards.json`。流程为：长者赠「火」「刀」脱险 → 亲笔制两张卡 → 残碑藤妖实战。旧版 `legacy.html` 中「一、人、止」等战斗内容不在本次生产范围。

表格中的数量是建议首批生产量；未实现内容须标记为“拓展建议”，不可写成已实现功能。

## 三、统一生成约束

你是《汉字成圣》的资源策划与文案编辑。

背景：寒冬纪元，主角沈砚在雪林受困，导师陆青崖赠卡救援。当前新手流程：接过三星火、刀赠卡 → 先火后刀脱险 → 亲笔制作火、刀双卡 → 对战残碑藤妖 → 入门完成。

### 规则约束

1. 长者赠卡使用后永久燃尽；第一场敌人不反击。
2. 自制卡可再次抽取，未使用的卡保留；残碑战每回合3文气。
3. 火施加灼痕，刀引爆灼痕；具体数值以提供的 JSON 为准。
4. 新手仅制作火、刀两张卡；失败不扣纸墨，重写不续时。不得套用旧版书写战斗的计时和资源规则。
5. 星级与品质是两个维度：自制卡可为一星完美或二星逸品，长者赠卡为三星完美；四至七星属于后续设计。
6. 玩家卡面主字来自玩家真实笔迹，插画中不要预先生成主字。导师笔迹与玩家笔迹分开管理。
7. 不得修改费用、伤害、灼痕、引爆、保留、燃尽和升级规则；不得虚构奖励或新增机制。

### 美术约束

- 水墨淡彩、宣纸质感、墨青人物、朱砂动作、灰青寒霜、赭金品质反馈；避免霓虹、大面积发光和塑料冰晶。
- 色板参考：纸白 `#eee8db`、旧纸 `#d7cdb9`、墨青 `#293b32`、朱砂 `#98483c`、灰青 `#597b79`、草绿 `#667c51`、赭金 `#957747`。
- 角色沿用现有参考图，保持面容、服装、道具、视角与比例一致；人物与道具不裁切。
- 透明资源须有真实透明背景，不用棋盘格、白底或黑底冒充透明。
- 插画、卡框与卡背不烘焙规则文字、费用、伤害数字或玩家主字；文本由界面另行叠加。
- 技能与制卡装饰独立于书写墨迹，不进入评分画布，不遮挡操作与信息。
- 现有 SVG 应优先输出矢量设计方案或可检查的 SVG；不要仅为重做资源而强行改成位图。

### 文本约束

- 中文，修仙语气，简练易懂，规则信息优先。
- 一句教学只教一个重点，失败反馈指出可改进动作，不羞辱玩家。
- 字源、典故、引文无可靠依据时标记“待核验”，不杜撰出处。
- 新建议单独标记“拓展建议”。

## 六、交付格式与处理顺序

每条资源至少包含：`id`、类别、名称、当前/拓展、使用场景、生成内容或完整绘图提示词、规格建议、变体、验收要点。文字资源额外包含触发事件、角色、字数限制和占位符；美术资源额外包含参考路径、透明要求、构图留白、推荐文件名和一致性约束。

建议按以下批次生成，避免一次生产全部资源导致风格漂移：

1. 导师教学、书写指导、失败反馈：T02、T03。
2. 两种敌人独立美术：A04、A05。
3. 火刀卡面画谱：A06、A07。
4. 主角与导师动作：A02、A03。
5. 场景分层、材料、卡框与反馈：A01、A08—A12。
6. 剧情、卡牌、战斗、图鉴与语音文本：T01、T04—T07。

各批次应输出资源清单和完整内容，不只给概述。优先检查规则准确性、角色一致性、卡面留白、文字长度与提示词可直接使用性。未确定的美术尺寸写为建议，不伪称当前实现要求。

若具备文件写入能力，生成结果放在 `docs/content/generated/tutorial/` 下，可按资源ID分文件，并生成 `资源清单.md` 索引。该目录是本次建议的交付位置。实际图片也先交付到独立待审目录，不覆盖现有资源。

本任务仅生成资源与要求交付物，不直接修改游戏代码、当前数据数值、玩家存档或语音缓存，不提交、不推送、不部署。资源审核后再进行接入。
